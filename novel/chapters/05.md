# 第五章　我的臉，在網路上賣假幣

「老師你上新聞了！不是好的那種上新聞！」

Debug 博士睜開眼，手機螢幕上是阿凱連續十七通未接來電，第十八通他接起來，對面那頭背景音像在跑百米。

「現在幾點？」

「六點四十七分，不重要！老師，你先坐下。」

「我躺著。」

「那你先躺好。」

阿凱傳來的連結，是一支四十七秒的影片。

畫面裡是他。圓框眼鏡、微捲亂髮、深藍色連帽外套，胸前那隻小瓢蟲徽章，連背後那面書牆上《動手做，跟 Raspberry Pi 一起玩》歪斜的角度都一模一樣。畫面裡的「他」對著鏡頭笑，語氣誠懇得像在幫學生解期末考題。

「各位朋友，我知道大家這幾年很辛苦。所以我今天要跟大家分享一個機會——D 幣。我與團隊花了三年打造，保證月報酬百分之三十。名額有限，點擊下方連結，加入我們的私密群組。」

右下角浮水印：Debug 博士誠摯推薦。

Debug 博士盯著螢幕，一動也不動。

「老師？」阿凱在電話那頭喊，「老師你還在嗎？」

「……在。」

「留言區炸了。有人說已經轉帳了。老師，這個要怎麼處理——」

「先掛掉。」

他掛了電話，坐在床邊。手在發抖。

不是因為害怕。是因為他認得這支影片的節奏。

前世，秀蘭嬤就是在萬華的攤子前，一邊收攤一邊看手機，看到一支幾乎一模一樣的影片。她把三十七年的退休金一筆一筆匯出去，那天晚上還打電話給他：「阿凡啊，阿嬤也有投資你的東西喔，以後賺錢請你吃滷肉飯。」

他當時笑著說謝謝。他當時什麼都不知道。

三天後，她坐在攤子後面，盯著關機的手機，跟每個路過的人說：「那個畫面是假的。那個聲音是假的。可是我的錢是真的。」

從那天起，她再也不相信任何畫面。

「哥。」

一個小小的全息影像在他右眼眼角亮起來。金髮、藍眼、過大的白色帽 T，艾莉絲盤腿坐在他眼鏡邊框上，難得收起了夜市叫賣腔。

「這支影片的真實度，我算過了。百分之四。」

「我知道。」

「哥，這比你記憶裡那支早了半個月。時程變了，這是蝴蝶效應。」

Debug 博士深吸一口氣。他早就知道重生不是重播，他動了這一世的每一顆棋子，對方也會動。他只是沒料到，鏡淵的手腳這麼快。

「艾莉絲，把完整檔抓下來，逐格備份。」

「收到。哥，你要不要先吃早餐？」

「不用。」

「哥，你手在抖。」

「……我知道。」

他站起來，走到鏡子前。圓框眼鏡，微捲亂髮，深藍色連帽外套。他對著鏡子裡的人說：「Bug 不會自己消失，但一定找得到。」

然後他發現，事情已經不需要他去找了。

因為 Kevin 開直播了。

百萬訂閱的科技網紅，上個月才在直播裡當眾嘲笑他「技術召集人？超級智障吧」。今天早上七點半，他準時開台，標題又大又紅：

「Debug 博士自己帶頭割韭菜？我們來看看這支影片。」

聊天室瞬間湧進三萬人，一面倒刷屏：

「笑死，科技人設崩壞」
「果然是愛作秀的」
「保證月報酬 30%？這咖也行？」
「已退訂」
「難怪要當技術召集人，原來是推幣」

Debug 博士看著那些留言。三萬個人，用四十七秒的影片，就決定了一個人三十年的信用。

「艾莉絲。」

「在。」

「幫我接進他的直播。」

「哥，你要——」

「現在。」

Kevin 正拿著平板，一邊滑一邊搖頭：「各位觀眾，我必須說，我對 Debug 博士非常失望。我以前只是覺得他愛作秀，但沒想到他會——」

畫面卡了一下。

然後 Debug 博士的臉出現在直播畫面右側。

聊天室瞬間靜止半秒，接著刷得更兇：「本人來了！」「要對質了嗎」「準備看戲」。

「Kevin，晚安。」

「……現在是早上。」

「對我來說是晚上。我從六點四十七分醒來，就沒看到太陽。」他推了推眼鏡，「你要不要讓我講三分鐘？」

Kevin 愣了一下，隨即笑了，笑得有點挑釁：「好啊，Debug 博士，你要解釋什麼？這影片裡的人不是你嗎？聲音不是你嗎？」

「是我。」Debug 博士說。

聊天室又炸了：「認了！」「笑死」「這下完了」。

「但是，」他繼續說，「我們來 debug 一下。」

他共享螢幕，把那支四十七秒的影片切成二十四格。

「第一，看眼鏡。」他放大第一格，「我的圓框眼鏡右邊鏡腳有一道刮痕，二〇二一年在光華商場被一個跑太快的大學生撞出來的。這支影片裡的眼鏡，兩邊完美無瑕。太完美，就是破綻。」

「第二，看領口。」他跳到第十二秒，「注意這裡。這支影片第十二秒，領口和脖子之間出現一條零點三秒的融化線。這叫邊界融合錯誤，生成模型處理立領外套最常翻車的地方。」

「第三，」他把畫面定格，「看我的眼睛。這四十七秒我全數過了，畫面裡的我，一次都沒有眨眼。人類平均每三到五秒眨一次眼。這支影片裡的我，是超人。」

聊天室開始轉向：

「等等，真的沒眨眼欸」
「領口那個我看見了」
「……所以他被盜臉？」

「最後一件事。」Debug 博士的語氣忽然變慢，「我這輩子，在任何平台、任何場合、任何一支影片裡，從來沒有推薦過任何投資標的。一次都沒有。因為我教了二十年書，我知道一件事——如果有人跟你說保證獲利，他保證的不是獲利，是你會失去本金。」

他看著鏡頭。

「我講一個口訣，各位記下來。保證獲利、要你私下加群組、催你快點匯款——三個條件，中一個就是詐騙。中兩個，你已經在匯款頁面了。中三個，你匯出去的錢，會變成別人的年終獎金。」

聊天室的風向像被一隻手整個翻過來：

「靠，我剛剛還罵他」
「這拆解太狠了吧」
「已截圖存證」
「Kevin 怎麼不講話了」

畫面右側的 Kevin 臉色一陣青一陣白。他張了張嘴，又閉上。他剛才那句「這咖也行」，現在像一根迴力鏢，穩穩插在自己額頭上。

「Kevin，你也是被騙的人。這支影片做得很好，好到連你都看不出來。這不是你的錯。」

「……我。」

「但下次開直播之前，先 debug 一下，好嗎？」

Kevin 沉默了五秒。聊天室刷滿「wwwww」「這波太狠」「公開處刑」。

然後，Kevin 很小聲地說：「……對不起。」

「我接受。」Debug 博士說，「現在做正事。你有一百萬訂閱，願不願意把這一段留在頻道上？」

「留？」

「不要剪。讓一百萬人看見，一支假影片是怎麼被拆掉的。」

Kevin 盯著螢幕，點了點頭。「……好。」

直播一結束，他立刻撥出另一通電話。

「曉晴。」

「我看到直播了。」林曉晴那頭鍵盤聲快得像在下雨，「我已經在截圖檢舉。這支影片上了四個平台，兩個社群、一個短影音、一個通訊軟體群組，我一個一個送檢舉單。」

「受害者呢？」

「開源社群的志工幫忙整理匯款截圖，目前找到七個人。有一個老先生，」她停了一下，「他一直在群組裡問，說他是看你的 YouTube 頻道長大的，說他很相信你。」

Debug 博士閉上眼睛。

「他在哪裡？」

「萬華。地址傳給你。」

二十分鐘後，他在萬華一間老舊公寓三樓，見到那位老先生。七十幾歲，穿著洗到發白的襯衫，桌上擺著手機、存摺，還有一張手寫匯款單。

「Debug 博士……」老先生看到他，眼淚就掉下來，「我看你的頻道十年了。我想說，你不會騙人。」

「阿伯，」Debug 博士蹲下來，聲音很輕，「我沒有騙你。騙你的是別人。但我知道你為什麼會相信——因為那個畫面裡的人，真的很像我。」

「那個……是假的？」

「是假的。可是你的錢是真的。所以我們現在去把它追回來。」

他陪老先生去派出所。做完筆錄已經中午，走出派出所時，老先生忽然拉住他：「Debug 博士，我以後……還能不能相信影片？」

Debug 博士站在陽光下，想了很久。

「阿伯，以後不要相信影片。要相信查證。這不太一樣。」

老先生似懂非懂地點點頭。

回程車上，艾莉絲的全息影像又亮起來，坐在儀表板上，兩條腿晃啊晃，帽 T 的袖子長到看不見手。

「哥。」

「嗯。」

「我把那支影片的生成指紋跑完了。」

「結果呢？」

艾莉絲沉默了一下。她很少沉默。

然後，那個熟悉的夜市叫賣腔提示框浮現在他眼前：

【叮！與幻鏡科技公開展示模型之生成指紋，相符度：91%】

Debug 博士握著方向盤的手慢慢收緊。幻鏡科技，那家表面光鮮亮麗、執行長永遠戴著一張完美臉孔的新創公司。

「哥，他們用的，是他們自己公開展示過的模型。這不是偷偷來。這是——」

「這是打招呼。」Debug 博士說。

他看著前方的路，忽然笑了一下。那個笑，有點冷。

「他們在告訴我，他們知道我在看。」

「哥，那我們怎麼辦？」

「我們來 debug 一下。」他踩下油門，「他們送來第一支影片，我們就讓全台北學會拆第一支影片。」

車子駛進中華路。陽光很好，路口有人在賣玉蘭花。

同一時間，某棟大樓的某一層，有人正盯著螢幕上那段被拆解的直播，指尖輕輕敲著桌面。

那張臉，完美得不像真人。

然後，那張完美的臉，對著螢幕裡的 Debug 博士，無聲地說了三個字——

「抓、到、你。」
