# 第十章　深偽之夜

「程博士，你那個什麼照妖鏡，擋得住十萬支影片嗎？」

晚上八點五十九分，真相守護聯盟的臨時辦公室裡，一位立場鮮明的志工當著所有人的面，把手機螢幕轉過來——上面是某個匿名群組的截圖：「今晚九點，讓台北知道什麼叫真相已死。」

「擋不住的話，你今晚就會變成全台灣最大的笑話。」

Debug 博士沒抬頭。

他盯著牆上那面白板，上頭紅線從「幻鏡科技」一路連到海外空殼、連到早已停業的機房，最後匯聚成一個問號。他推了推圓框眼鏡，胸前那隻小瓢蟲徽章在燈下反了一下光。

「我們來 debug 一下。」他說，「笑話跟傳說，差別只在於——誰活到最後。」

「哥，」艾莉絲的全息影像浮在他右眼視野角落，白色帽 T 的帽子拉得老高，藍眼睛裡罕見地沒有笑意，「對時完成。全網監測網上線，照妖鏡主機待命，開源社群分流節點……一百四十七台，全綠。」

「一百四十七台？」他吹了聲口哨，「上個月還只有三十一台。」

「秀蘭嬤滷肉飯攤那群阿姨幫忙架的。」艾莉絲的語氣瞬間切換成夜市叫賣腔，「她們講，『囝仔，這個比抓寶可夢好玩』，還問說破關有沒有送滷蛋。」

「有。」他笑了一下，「破關我請全攤吃三輪。」

然後，九點整到了。

辦公室的燈閃了一下。

不是停電，是螢幕。所有螢幕同時亮起——阿凱桌上那台二十七吋、林曉晴手裡的平板、走廊盡頭那台原本只播新聞的電視。

十萬支影片，同一秒，灌進全台北。

「來了。」阿凱的聲音有點抖。

第一支影片裡，一位候選人坐在偵訊室桌前，低著頭，聲音沙啞：「我承認……我收了不該收的錢。」逼真到連鬢角那顆痣的位置都對。

第二支是假停電通知，用公家機關名義，說明天投票所「因設備異常全面關閉」。

第三支更狠，直接把幾十個投票所地址改到山區。

第四支，是Debug 博士自己。

影片裡的「他」坐在鏡頭前，語氣誠懇得令人發毛：「各位鄉親，我是Debug 博士。這次選舉的系統有漏洞，為了避免混亂，我呼籲大家明天不要去投票。」

阿凱轉頭：「你什麼時候拍的？你昨晚不是跟我一起吃鹹酥雞？」

「那不是我。」他的聲音很平，「那是三%真實度的我。」

【叮！偵測到深偽影片，真實度：3%】

【全網即時掃描中……已識別：11,482 支……23,905 支……】

「照妖鏡，上線。」他按下 Enter。

下一秒，林曉晴從資料組衝出來，頭髮亂得像剛跑完馬拉松。

「流量爆了！主機撐不住！再這樣下去三分鐘就掛！」

「撐不住就分流。」他頭也不回，「賈仁義的機房呢？」

「他……」林曉晴愣了一拍，「他十分鐘前主動打來，說機房全部開放，算力免費借我們。還說『這不是幫誰，是幫真相』。」

Debug 博士嘴角抽動了一下。「那個傲慢的老頭。」

「他補充說，『我還是覺得你們這群人很吵』。」

「這才像他。」

機房裡，賈仁義親自站在機櫃前，襯衫袖子捲到手肘，對著工程師大吼：「備援全部切過去！現在！誰再跟我說一句『不符合成本』，我就叫他去掃廁所！」

同一時間，Kevin 的直播間衝上十萬人。

他沒化妝，頭髮像鳥窩，穿著一件印有「我原本只會開箱手機」的 T 恤。

「各位觀眾，今晚不業配。」他指著螢幕，「這支說候選人認罪的影片，看這裡——他眨眼頻率每兩秒一次，人類不會這樣眨。再看這裡，光影方向跟背景光源差了十五度。假的。」

聊天室刷成一片。

「Kevin 你怎麼突然變專家？」

「因為有人教過我，」他頓了一下，語氣難得正經，「畫面會騙人，但你可以學會怎麼問問題。」

萬華巷口，秀蘭嬤的滷肉飯攤還亮著燈。幾十個阿姨圍著手機，把查證連結一條一條貼進家族群組、里民群組，還有那個永遠在傳長輩圖的群組。

「這支假的，不通轉！」

「啊這個連結怎麼那麼長？」

「妳就複製貼上，免驚！」

辦公室窗邊，Debug 博士看著城市燈火。

第一波，擋住了。

他知道，這太順了。

「艾莉絲。」

「哥，我知道你要問什麼。」她的聲音低了下去，「依鏡淵的行為模型，第一波是餌。第二波才是刀。」

話才說完，阿凱的電腦發出一聲提示音。

「程博士……」阿凱的聲音乾得像砂紙，「你看這個。」

螢幕上，是秀蘭嬤。

七十八歲的她坐在攤子後方，圍裙還繫著，眼淚一滴一滴掉進滷肉鍋的熱氣裡。

「阿凡……阿凡伊講會照顧我……」影片裡的她哭得肩膀發抖，「我那筆退休金，攏總予伊騙去啊……逐家毋通信伊……」

Debug 博士的手，停在半空中。

辦公室的聲音好像全被抽走了。

他認得那個圍裙。他認得那個鍋子。他認得那個他學生時代吃了四年、從來沒被收過一毛錢的背影。

前世，二〇六一年，他八十歲，坐在養老院的電視前，看著一模一樣的畫面。那天之後，秀蘭嬤沒有再來過攤子。那天之後，她不再相信任何畫面。

「真實度……」他的聲音裂開，「多少？」

艾莉絲沉默了三秒。

【叮！偵測到深偽影片，真實度：97%】

「哥，他們的模型，進化了。」

「不可能……」林曉晴衝過來，「秀蘭嬤本人根本沒錄過這段！這是假的！」

「我知道是假的。」Debug 博士說。

「那你——」

「我知道是假的，」他重複，聲音很輕，「但全台北，不會知道。」

他站在原地，一動不動。

那三秒，他像被拉回前世那間養老院，拉回那三十五年的後真相時代。他想，是不是不管重來幾次，他都救不了那個給他飯吃的人。

「哥。」艾莉絲喊他。

他沒反應。

「哥！」

「程博士！」阿凱也喊，「聊天室開始燒了！有人說『連阿嬤都出來指證』！」

「這下真的完了……」那位志工低著頭，「我早說擋不住。」

就在這一刻，辦公室的門被撞開了。

一個穿著圍裙、手裡拿著鍋鏟的阿嬤衝了進來，後面跟著兩個攔不住她的志工。

「啥物假的阿嬤？」秀蘭嬤舉起鍋鏟，對著直播鏡頭，中氣十足，「我在這！我人好好站在這！」

全辦公室愣住。

「逐家看喔！」她轉頭對阿凱喊，「少年仔，鏡頭拿過來！給全台灣看！」

阿凱手忙腳亂地把直播切過去。

秀蘭嬤把鍋鏟往桌上一拍，發出「鏘」一聲巨響。

「啥物講阿凡騙我？彼個假的阿嬤，是啥物人做的？啊伊是會曉煮滷肉飯嗎？伊知影滷肉要煨三個鐘頭嗎？」

聊天室瞬間爆炸。

「阿嬤本人！！！」

「鍋鏟流防詐！！！」

「這才是真人認證啦！」

秀蘭嬤越講越氣，圍裙一甩：「阿凡這個囝仔，讀冊的時陣，逐工來我這食飯，我從來無收伊半圓。伊若欲騙我，早就騙啊！哪會等到今仔日？」

她頓了一下，聲音突然軟了。

「伊是會記得我生日、會記得我愛食啥物、會記得我腳不好、逐個月來看我的人。」

她轉頭，看著站在那裡、眼眶紅著的Debug 博士。

「阿凡從來不會騙人。」

全網安靜了半秒。

然後，爆了。

「哭死。」

「我阿嬤也是這樣講話的。」

「今晚滷肉飯免錢！守夜人來吃！」秀蘭嬤舉起鍋鏟，像舉起一支勝利的旗子，「我講到做到！來喔來喔！」

那位剛才還在唱衰的志工，默默把手機收進口袋，低下頭，耳根整個紅了。

風向，在那一分鐘裡，徹底翻了過去。

Debug 博士吸了一口氣，把眼鏡推回鼻樑。

「艾莉絲。」

「哥，我在。」

「第二波他們用了進化模型，代表投放伺服器一定有指紋。」他的聲音重新變得飛快，「照妖鏡改寫，不掃影片了，掃伺服器。沿著投放源頭，一路回溯。」

「哥，那個算力需求——」

「我知道。」他打斷她。「做。」

艾莉絲看了他一眼。那一眼很長。

「好。」她說，「哥，坐穩了。這趟車，油門催落去。」

【照妖鏡．溯源模式，啟動】

【算力調度中……】

那一刻，Debug 博士感覺腦子裡有什麼東西被輕輕抽走。像有人翻過一本書，撕掉其中一頁。

他想不起來，前世某個下午，他到底跟誰喝過咖啡。

他甩甩頭。不重要。

「鎖定中……」艾莉絲的聲音帶著雜訊，「跳了十七個國家、四十二個節點……哥，他們很會躲，躲得像夜市裡跑給警察追的攤販。」

「比我們會躲，但沒我們會算。」他盯著螢幕，「繼續。」

【座標收斂……87%……94%……】

「找到了。」艾莉絲說，「內湖，一棟商辦大樓，十七樓。訊號源頭跟幻鏡科技的登記地址，差三條街。」

Debug 博士抓起手機。

「警察嗎？我是Debug 博士。我有一個座標，還有一整套投放紀錄的雜湊值。你們破門的時候，記得開直播。」

凌晨，內湖。

十七樓的門被撞開時，莫無影正坐在一整面牆的螢幕前，對著鏡頭調整領帶。他臉上那張完美的臉，正在直播。

「各位，台北已經沒有真相了。」他微笑，「你們看，連一個阿嬤都可以被製造出來。從今晚開始，沒有人會再相信任何畫面。這，就是我送給這座城市的——」

門被撞開的聲音，透過直播傳了出去。

莫無影回頭。

鏡頭，也跟著回頭。

然後，全台灣都看到了——

那張完美得不像真人的臉，在強光下突然出現一格一格的馬賽克。先是嘴角，再來是鼻樑，最後整張臉像壞掉的螢幕，一塊一塊崩解。

底下，是一張很平凡的臉。

有點疲憊、有點驚慌、有點普通。像任何一個在捷運上會遇到的上班族。

他愣住，伸手去摸自己的臉。

「不要拍……」他說，「不要拍我……」

全網截圖。

「原來長這樣。」

「這張臉，好普通。」

「普通到……有點可憐。」

十一點五十九分。

照妖鏡後台跳出一行數字。

【本夜攔截深偽影片：100,341 支】

【已標註／下架：99.2%】

【平均辨識時間：47 秒】

城市安靜了下來。

辦公室的燈還亮著，但沒有人說話。阿凱癱在椅子上，林曉晴靠著牆滑坐在地，賈仁義在機房裡睡著了，Kevin 的直播間還開著，畫面是他趴在桌上打呼。

秀蘭嬤在樓下煮滷肉飯，香味一路飄上來。

Debug 博士站在窗邊。

「哥。」艾莉絲的聲音很輕，輕得像快聽不見。

他轉頭。

她的全息影像站在他旁邊，白色帽 T 好像變得更透明了。他透過她的肩膀，看見了後面的白板。

「艾莉絲，妳——」

「哥，我用了太多算力。」她笑了一下，藍眼睛還是那麼亮，「你知道代價的。」

他愣住。

「妳是說——」

「每一次大算力，你就會少一段記憶。」她說，「今晚，用了很多次。像夜市那種『一支三塊、三支十塊』的促銷，只是這次打折的是你的腦袋。」

Debug 博士張了張嘴。

他想說，那不重要。

但話到嘴邊，他突然發現，他想不起來，前世那個下午，他到底為什麼哭過。

「哥，」艾莉絲往前一步，聲音帶著濃濃的台灣國語，「這一次，我們守住了喔。」

「艾莉絲——」

「三十三天，」她數著，「從你在真相守護聯盟成立記者會那天被推上來，到現在。」

「妳不要——」

「記得幫我吃一碗滷肉飯。」她說，「要加滷蛋。要跟秀蘭嬤說，是我說的。還有，跟她講，她今天那一鍋鏟，比全台灣的伺服器都夠力。」

她的影像，一格一格淡了下去。

「哥，」她的聲音越來越遠，「Bug 不會自己消失，但一定找得到……你教我的。」

然後，消失了。

辦公室裡，只剩下他一個人，還有滿室的滷肉香。

Debug 博士站在那裡，很久很久。

然後他推了推眼鏡，轉身下樓。

「秀蘭嬤，」他說，聲音有點啞，「一碗滷肉飯，加滷蛋。」

「還有一碗，」他頓了一下，「放旁邊。」

秀蘭嬤看了他一眼，沒問為什麼。

「好。」她說，「趁熱。」

午夜十二點，台北的燈火一盞一盞熄了。

但在萬華的巷口，那盞燈還亮著。一群人正吃著免錢的滷肉飯，一邊笑，一邊哭，一邊把查證連結貼進每一個群組。

而距離投票日，還有不到二十四小時。

只是沒有人知道——那一碗放在旁邊、冒著熱氣的滷肉飯，究竟是等誰回來吃。
