# 第四章　黑客松上的一行程式碼

「兩個人？你們這隊只有兩個人？」

報到處的工讀生拿著隊伍名冊，表情像看到有人拿悠遊卡要搭高鐵。

「對，兩個。」Debug 博士把識別證掛好，深藍色連帽外套、圓框眼鏡，胸前的小瓢蟲徽章晃了一下，看起來像來修印表機的。

「請問……另一位呢？」

「我就是另一位。」阿凱舉手，嘴裡還咬著超商飯糰，「老師，我們現在退出還來得及嗎？我昨天才聽說隔壁隊有六個人、三台高階筆電，還帶了一台小型伺服器。」

「來不及。你是我唯一的前端工程師。」

「你也是我唯一的老師啊，這有什麼好驕傲的！」

【叮！會場掃描完成。攝影機三台、直播兩路、評審五人。哥，今天很熱鬧喔，比夜市還擠～】

艾莉絲的全息影像跳到他右眼視野，金髮藍眼，白色帽 T 晃啊晃，身高只到他肩膀。

「艾莉絲，今天少講話，我要專心。」

【好啦好啦。不過哥，你左邊那個穿西裝的，表情有百分之十七的時間是僵的，建議多觀察。】

台上，主持人遞出麥克風。

梳油頭、深藍西裝的中年男人接過，笑得像一張印壞的發票。

賈仁義。自稱「台灣 AI 教父」，臉書每天發文，開口閉口「我在矽谷的時候」。

「各位年輕朋友，AI 不會騙人，會騙人的是人。」他張開雙臂，「我常說，深偽問題被誇大了，大家不要自己嚇自己。今天主題『AI 守護城市』很好，但重點是——不要發明問題，要解決問題。」

台下掌聲熱烈。

Debug 博士沒鼓掌。

阿凱壓低聲音：「老師，你怎麼不拍手？」

「我在數他這句話裡有幾個 bug。」

「幾個？」

「兩個。第一，AI 不會騙人是錯的——AI 不會『主觀想騙人』，但它會『被拿來騙人』。第二，深偽被誇大？那是他沒被騙過。」

【哥，你講話真的很像在 debug。】

「安靜。」

報名組隊時，Debug 博士在志工名單上看到一個名字。

林曉晴。二十九歲，開源社群志工、資料記者。短髮，素色外套，桌上貼滿便利貼，筆電外殼貼著一張「問問題是權利，查證是義務」。

Debug 博士走過去：「林曉晴？我是——」

「我知道你是誰。」她頭都沒抬，「那個 YouTuber，Debug 博士。上個月在影片上講 AI 詐騙講了二十分鐘。」

「對，我想邀請妳——」

「不用。」她終於抬頭，眼神冷得像剛從冰箱拿出來，「網紅來黑客松？作秀吧。你們這種人寫的程式碼，我猜是小編寫的，你負責剪綵。」

阿凱在後面「喔」了一聲，很識相地退開三步。

Debug 博士愣了一下，最後只是笑：「好，那我自己寫。」

「請便。」林曉晴低頭繼續敲鍵盤。

【哥，她心跳有點快耶。她其實很緊張。】

「艾莉絲，不要偷聽人家心跳。」

【我沒有偷聽，我是掃描。差很多好不好。】

於是，全場最寒酸的隊伍誕生了。

兩個人。一台筆電。一壺超商咖啡。

隔壁隊六個人，桌上三台高階筆電、兩台大螢幕，還有一台嗡嗡作響的小型伺服器。戴棒球帽的年輕人探頭過來：「學長，你們這隊……只有兩個人喔？」

「精實。」Debug 博士說。

「我們決定叫你們『老人隊』。」另一個女生笑，「開玩笑的啦，加油喔。」

阿凱臉都綠了。

上午十點，主題公布：AI 守護城市。

Debug 博士在白板上寫了三個字：照妖鏡。

「阿凱，我們做一個開源的深偽檢測工具。」

「二十四小時？老師，你知道深偽檢測是什麼等級嗎？那是大公司在做的耶。」

「所以我們不做大公司的東西。我們做一個——手機打開、上傳影片、三秒告訴你『這支影片有問題』的東西。」

「三秒？」

「不夠快就沒人用。阿嬤不會等三十秒。」

阿凱沉默兩秒，把袖子捲起來：「好。介面我做，模型你負責。但老師我先講，我不加班到天亮。」

「你會加。」

「我會加。」阿凱認命地打開編輯器。

【叮！哥，我可以幫你算光影一致性的矩陣，大概省你六小時。】

「不用。」

【蛤？為什麼不用？我很強耶。】

「因為程式碼要人寫，才能開源給所有人。」Debug 博士敲著鍵盤，「如果這東西只有妳算得出來，那它就不是工具，是黑盒子。黑盒子救不了民主。」

【……哥，你講話好繞口。】

「聽不懂？」

【聽得懂。就是，你要讓大家都能自己照妖，不能只有你有照妖鏡。】

「對。」

【那我可以幫你檢查 bug 嗎？】

「可以。這個可以。」

二十四小時裡，他們做了三件事。

第一，光影檢測。深偽最常死在光線——臉部高光跟環境光源對不上，像貼上去的。

第二，眨眼頻率。真人平均每分鐘眨十五到二十次，深偽常常眨太少，或眨得像機器人。

第三，唇形與聲音同步。這是關鍵。音節的爆破點對不上嘴型，差零點零幾秒，人眼看不出來，程式看得出來。

凌晨三點，阿凱趴在桌上睡著了。Debug 博士幫他蓋上外套，自己繼續寫。

【哥，你的肝在抗議了。】

「讓它抗議。」

【你前世就是這樣死的嗎？】

Debug 博士的手指停了一下。

「不是。前世我活到八十歲，看著台北一點一點不相信任何畫面。那比爆肝難受。」

【……】

「艾莉絲，幫我把唇形同步的權重調低。太敏感了，會誤判。」

【好。哥，這樣準確率會掉零點五趴喔。】

「掉就掉。我寧可漏抓，也不要冤枉人。照妖鏡如果會亂指人，那它自己就是妖怪。」

【……哥，這句話我要記下來。】

「記在心裡就好，不要寫在程式碼註解裡。」

【來不及了，我已經寫了。】

第二天下午，決賽 demo。

台下坐滿評審、參賽者、好幾台直播攝影機。賈仁義坐在正中間，笑容標準。

Debug 博士上台，只帶一支手機。

「各位，我們的工具叫『照妖鏡』。上傳影片，三秒，告訴你哪裡有問題。」

「就這樣？」賈仁義挑眉，「博士大人，市面上不是很多了嗎？」

「市面上很多，但要付費、要註冊、要上傳到別人的伺服器。」Debug 博士說，「我們的不用。全部在手機上跑，不上傳、不留紀錄、開源。」

賈仁義笑了笑，轉頭對助理說了幾句。助理遞上一個隨身碟。

「好，那我來測試。」他把隨身碟插進電腦，「這是我上個月在一場論壇的演講影片。你測測看，是不是真的。」

全場安靜。

Debug 博士接過影片，上傳。

三秒。

手機螢幕跳出紅色框線，圈住賈仁義的臉，旁邊一行字——

【光影不一致：臉部高光方向與背景光源相差 41 度】

【眨眼頻率：每分鐘 3 次（真人平均 15–20 次）】

【唇形與聲音不同步：誤差 0.12 秒】

【綜合判定：深偽，真實度 6%】

全場先是死寂，然後爆笑。

賈仁義的臉從白變紅，從紅變青。

「這、這不可能！這是我本人的演講！」

助理在旁邊小聲：「老闆……那個……那支影片是……我請 AI 生成的，想說您沒空錄，先用這個交差……」

「你什麼？！」

笑聲更大。有人笑到拍桌，有人手機掉到地上，直播聊天室整排刷過去。

Debug 博士沒有笑。他把手機放下，看著台下。

「各位，這支影片不是誰的陰謀，就是一個偷懶的助理。但各位想一想，如果連評審的影片都可以這樣生出來，那選舉前夜，會發生什麼事？」

全場慢慢安靜。

「所以我要宣布一件事。」Debug 博士打開投影，秀出一行程式碼。

`SPDX-License-Identifier: MIT`

「照妖鏡，全部開源。不屬於我、不屬於任何陣營。任何人都能用。包括——」他頓了一下，「包括所有候選人的團隊。包括對手的團隊。」

台下一片嘩然。

「深偽不挑陣營，」Debug 博士說，「照妖鏡也不挑。」

他走下台。

林曉晴坐在最後一排，筆電螢幕亮著，手指停在鍵盤上，愣了整整五秒。

【叮！哥，那個林曉晴心跳現在一分鐘一百二十下。她不是緊張，她是——】

「艾莉絲。」

【好啦好啦，我不講。】

頒獎。照妖鏡拿了「社會貢獻特別獎」。第一名是隔壁隊的智慧路燈。Debug 博士覺得很合理，路燈比較可愛。

散場時，林曉晴走過來。

「你剛剛那一行授權宣告，」她看著他，「是認真的？」

「MIT 授權，開源授權裡最寬鬆的一種。任何人都能改、能用、能商用，只要保留著作權聲明。」

「我不是問法律，」她說，「我是問，你是不是認真的。」

Debug 博士推了推眼鏡：「我以前看過太多人，因為一支假影片，就再也不相信任何畫面。阿嬤、鄰居、我自己的學生。那不是技術問題，那是信任破產。」

他停了一下。

「所以照妖鏡不能是我的。它要是大家的。」

林曉晴看著他，很久。

然後她伸出手：「我加入。」

「歡迎。」

「先說好，我不是相信你，我是相信那一行程式碼。」

「這樣就夠了。」

阿凱在後面大喊：「老師！她加入了！我們從兩人隊變成三人隊了！戰力提升百分之五十！」

「阿凱，數學不是這樣算的。」

「差不多啦！」

三人走出會場大門，天已經黑了。

門口站著一個男人。

西裝筆挺，笑容完美。完美到有點不對勁，像打過蠟，像剛從型錄上走下來的。

他在鼓掌。

「Debug 博士，」男人的聲音很輕、很順，「精彩。真的精彩。『深偽不挑陣營，照妖鏡也不挑』——這句話，我會記住。」

他遞上一張名片。白底黑字，設計極簡。

幻鏡科技　執行長　莫無影

Debug 博士接過名片，指尖有點涼。

「莫執行長，你們公司做什麼的？」

「我們做夢。」莫無影微笑，「我們讓人們看見他們想看見的東西。」

他轉身走了。皮鞋踩在柏油路上，一聲一聲，很穩。

【叮！警報！警報！】

艾莉絲的全息影像突然炸開，白色帽 T 都歪了。

【哥！那個人！那個人臉部真實度——】

【零趴！】

【他是零趴！哥！他的臉不是他的臉！】

Debug 博士站在原地，名片在手上，微微發燙。

距離投票日，還有二十六天。
