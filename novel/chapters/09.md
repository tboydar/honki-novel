# 第九章　投票前十天，全城真相守夜人

「程博士，你管得了假影片，管得了我這張嘴嗎？」

十一月十九日上午，Debug 博士才剛在真相守護聯盟的臨時辦公室坐下，一個自稱「資深政治觀察粉專」的小編就殺進來，手機懟到他鼻尖。螢幕上是一張截圖，紅字標題寫著「獨家！內部封關數字流出」。

「依法從昨天起不能公布民調了，」小編冷笑，「但這是『網友整理』，不歸法管吧？你報警啊。」

辦公室裡七八個志工全停下動作。有人手機已經舉起來錄影。

【叮！後設資料掃描：此圖三次轉存，首發帳號註冊於三天前，大頭貼為生成圖像，真實度：2%】

「不用報警。」Debug 博士推了推圓框眼鏡，聲音不大。「我們來 debug 一下就好。」

他把截圖放大，投影到牆上。

「各位看這個字型。這張圖用的字體，是二〇二四年才釋出的版本。但這張圖自稱是『兩週前流出的內部文件』。」

小編臉色變了。

「還有，這行小字——『本表僅供內部參考』——底下的浮水印，是某個免費線上製圖網站的預設圖案。」他轉頭，「阿凱。」

「在。」角落的前端工程師頭也不抬，「我查到了，同一個帳號昨天發了十四張『獨家』，每張數字都不一樣。」

全場爆出一陣笑。小編的手機被旁邊一個大學生不小心撞掉在地上，撿起來時手還在抖。

「關了正門，大家開始爬窗。」Debug 博士把投影關掉，「而且爬的還是別人家的窗。各位，看到『最新民調』截圖，第一件事不是轉傳，是懷疑。」

「哥，講得好！」艾莉絲的聲音從眼鏡邊緣飄出來，金髮藍眼的全息影像只到他肩膀高，穿著過大的白色帽 T，「不過我補充一下，這張圖連造假都造得很懶，夜市賣盜版 DVD 的阿伯都比他用心。」

「艾莉絲。」

「好啦好啦，我閉嘴。」她縮了縮脖子，「但哥，我剛剛為了掃這張圖，燒掉零點三趴的電。你要記帳喔。」

Debug 博士心裡揪了一下。他沒說破。

當天下午，他跟林曉晴約在萬華一間老咖啡店。林曉晴一坐下就把筆電轉過來，螢幕上是一份名單。

「工程師十七個、資料記者五個、大學生社團三個、里長……兩個。」她推了推眼鏡，「還有你阿嬤那邊，她說夜市攤商阿姨們可以出二十個人。」

「二十個？」

「她說：『查證這種事，阮攤商最會。客人拿假鈔來，我們一摸就知道。』」

Debug 博士笑了。笑著笑著，眼眶有點熱。

「所以我們要做什麼？」林曉晴問。

「做一件很笨的事。」他把一張紙推過去，上面只有六個字。

**沒查證，不轉傳。**

「就這樣？」

「就這樣。」他說，「法律只能事後罰。真正會讓假訊息死掉的，不是法規，是鄰居。」

林曉晴盯著那六個字看了很久，然後點頭。「名字呢？」

「真相守夜人。」

「……有點中二。」

「中二才好記。」Debug 博士理直氣壯。「而且我本來就是個中二講師。」

接下來三天，他們在萬華一間活動中心辦集訓。

第一堂課，台下坐著二十幾個攤商阿姨，人手一支手機，螢幕亮度全開，像一片小型燈海。

「阿姨，」Debug 博士站在白板前，「看到那種『名人推薦投資』的影片，第一步是什麼？」

「報警！」有人喊。

「很好，但報警之前呢？」

「……不要匯錢？」

「再前面一步。」

全場安靜。

秀蘭嬤舉手，慢慢站起來。她今天穿了件棗紅色外套，頭髮梳得整整齊齊。

「先不要傳給別人。」她說，聲音不大，但整個活動中心都聽見了。「我這輩子最後悔的，就是那天看到影片，第一個念頭是『要趕快告訴我妹妹』。」

空氣凝住了三秒。

Debug 博士看著她，喉頭動了一下。「阿嬤說得對。假訊息不是靠一個人相信才活下來的，是靠一群人轉傳才長大的。我們每轉一次，就是幫它施肥。」

「所以阮的口號是？」

「沒查證，不轉傳！」二十幾個阿姨整齊喊出來，氣勢比任何造勢晚會還猛。

第二堂課換大學生上場。林曉晴教他們看影片的後設資料：拍攝時間、裝置型號、壓縮痕跡。

「這支影片說它是昨晚拍的，但它的編碼格式是三年前的舊規格。」她指著螢幕，「就像有人跟你說這是今天現煮的，但碗底印著去年的保存期限。」

「老師，那如果對方把資料都洗掉了呢？」

「那就交給照妖鏡。」Debug 博士接過滑鼠，投影切到一個開源介面。「免費、開源、任何人都能用。它不完美，但它會告訴你：這支影片，有幾成的機率不是真的。」

【叮！掃描完成，真實度：7%】

台下驚呼。

「七趴？」有個大學生舉手，「那不就是假的？」

「九成三是假的。」Debug 博士糾正，「剩下的七趴，是它還留了一點破綻給我們抓。抓 bug 就是這樣，」他頓了一下，「Bug 不會自己消失，但一定找得到。」

第三堂課是里長場。Debug 博士教他們一件事：在群組裡，不要只貼「這是假的」，要貼「這是假的，這裡查得到」。

「長輩不是不相信真相，」他說，「他們是不知道去哪裡找真相。你給他一個連結，比跟他吵十句有用。」

有個里長舉手：「博士，如果我自己也看不出真假怎麼辦？」

「那就說：『這個我還沒查證，先不要傳。』」Debug 博士攤手，「承認不知道，是守夜人的第一課。」

第四天，門口出現一個熟悉的身影。百萬訂閱的科技網紅 Kevin，帽 T 帽子拉得低低的，像做錯事的小孩。

「我……」他站在門邊，搔了搔頭，「我來報到。」

全場安靜。那個在聯盟成立記者會上當眾笑「技術召集人？超級智障吧」的人，現在站在這裡。

「我欠大家一次。」Kevin 說得很慢，「我頻道有百萬訂閱，我以前覺得那是我很會講話。現在我知道，那是我很會放大聲音。放大聲音不難，難的是放大之前先查證。」

他抬起頭。

「我可以拍一支影片，教大家怎麼辨識深偽。不業配、不開營利、不掛任何人的名字。」

Debug 博士走過去，拍拍他的肩。「歡迎加入，守夜人。」

「……我可以不要叫守夜人嗎？聽起來像保全。」

「不行。」

第五天下午，又一輛車停在門口。車門打開，走下來一個穿訂製西裝、頭髮梳得一絲不苟的人。

賈仁義。自稱「台灣 AI 教父」的那位。

他站在門口，表情像吞了一顆沒剝皮的荔枝。

「我……」他清了清喉嚨，「我那支演講，是我錯了。」

全場沒人講話。這比任何打臉都狠。

「我當時說『AI 不會騙人，會騙人的是人』。」賈仁義的嘴角抽了一下，「這句話對一半。AI 不會自己騙人，但會被人拿來騙人。我身為做這行的人，講那種話，是傲慢。」

他從公事包拿出一份文件。

「我公司的伺服器，可以無償支援你們的檢測流量。到投票日為止。」

Debug 博士看著他，然後伸出手。「賈董，歡迎。」

「……不要叫我董。」

「那叫什麼？」

「叫……老賈就好。」他別過頭，「還有，我沒有要加入守夜人。我只是，提供伺服器。」

「當然。」Debug 博士憋笑。「守夜人不需要你，伺服器需要你。」

接下來幾天，他們把通報流程一條一條接起來。平台的公開檢舉窗口、查核機構的通報信箱、選務機關的客服專線，全部做成一個流程圖，貼在辦公室牆上，像一張作戰地圖。

「這不是我們一個團隊的事，」Debug 博士在會議上說，「這是整座城市的事。我們不是要贏，我們是要讓大家在投票那天，還看得到真的東西。」

林曉晴在旁邊補一句：「不同立場，也能一起 debug 民主。」

「這句借我當標語。」

「版權費。」

「請妳吃滷肉飯。」

「成交。」

只有一件事，Debug 博士一直放在心上。

艾莉絲的話越來越少。以前她會在他耳邊喊「哥～來喔來喔，深偽影片一支三塊，買五送一」，現在她只在必要的時候出現，講完就退回去。

「艾莉絲。」

「嗯。」

「妳在省電，對不對？」

沉默了三秒。

「哥，」她的聲音很輕，「我的算力不是無限的。每一次大掃描，都要燒一點。我想……把子彈留到最後一天。」

「最後一天是什麼時候？」

「你知道的。」

他當然知道。十一月二十七日，晚上九點。

那天晚上，他收到一則訊息。沒有署名，沒有帳號，只有一張照片。

照片裡是秀蘭嬤的攤子。帆布棚、紅色塑膠椅、那鍋滷得油亮的滷肉。拍得很近，近到看得見鍋邊的水氣。

下面一行字：

**「你守得住一座城，守得住一碗飯嗎？」**

Debug 博士盯著那行字，手指冰涼。

「哥。」艾莉絲的聲音在耳邊響起，比平常清楚一點，像是她刻意把最後一點力氣擠出來。「這是在嚇你。嚇人不用成本，查證才要。」

「我知道。」

「那你要怎麼回？」

他想了很久，然後把手機放下。

「不回。」他說，「回訊息是浪費子彈。我們把城守好，飯就守得住。」

十一月的台北，雨下得像有人在天空倒水桶。當晚他撐著傘走到萬華，秀蘭嬤的攤子還亮著燈。阿嬤正在收桌，看到他來，二話不說盛了一碗。

「阿凡，坐。」

「阿嬤，這麼晚還不休息？」

「守夜人啊，」秀蘭嬤把碗推過去，語氣像在講今天菜價，「你那個守夜人的名單，阮攤商阿姨攏總二十三個，明仔載開始排班。客人若拿手機來問『這甘有影』，阮就替伊掃。」

Debug 博士低頭扒了一口飯，滷汁鹹香，燙得他說不出話。

「還有，」阿嬤從圍裙口袋掏出一張護貝過的紙，「這是阮的攤位地號、阮的名字、阮的身份證字號後四碼。你若欲查證，查阮就好。阮這碗飯，正正當當。」

那張紙被雨氣弄得有點軟。Debug 博士接過來，手指在護貝膜上摩了一下。

「阿嬤，這張我收好。」

「收好就好。」她轉身洗碗，「恐嚇這種東西，」水聲嘩啦嘩啦，「你若越怕，伊就越爽。阮做生意的，看多了。」

十一月二十六日深夜，辦公室的燈還亮著。牆上的流程圖被便利貼貼滿，桌上堆著吃了一半的便當。林曉晴趴在桌上睡著了，Kevin 在角落剪片，老賈的伺服器監控畫面在另一台螢幕上跳著綠燈。

Debug 博士走到窗邊。樓下那塊電子看板，終於換成了查核機構的宣導字樣。

他看了一眼手錶。

十一月二十七日，晚上八點五十九分。

距離那個他記了三十五年的時刻，還有一分鐘。

「艾莉絲。」

「在。」

「子彈上膛了嗎？」

「上膛了，哥。」她的聲音有點抖，但還是那個夜市腔。「不過先講好，打完這一仗，你要幫我買一碗滷肉飯，放在眼鏡前面，讓我聞一下。」

「……好。」

「加一顆滷蛋。」

「好。」

「還要切仔麵。」

「艾莉絲。」

「好啦好啦，」她笑了，投影閃了一下，「哥，倒數十秒。」

他推了推眼鏡，看著窗外那片被雨洗得發亮的台北夜空。

「來吧。」
