天亮了，台北自己選

時間：2026 年 11 月 28 日，投票日

一分鐘悅讀8 格漫劇分鏡，先睹為快

「程博士，你那個 AI 妹妹呢？怎麼不叫她出來講兩句？」

清晨六點，投票所外的隊伍裡，一個穿競選背心的阿伯認出他，故意放大音量。旁邊幾個人立刻轉頭，像在看動物園裡剛跑出來的稀有動物。

「對啊，」另一個阿姨接話，「新聞說你昨晚那個什麼守夜人，是不是電腦當機了？我兒子講，那個 AI 根本是假的啦。」

Debug 博士推了一下圓框眼鏡。

鏡片上一片空白。沒有提示框，沒有「哥～」，沒有那個帽 T 大到快拖地的金髮少女跳出來嗆聲。

「她……休息了。」他說。

「休息？」阿伯笑出聲，「AI 也會休息喔？啊不就程式？關掉就沒有了吧。」

隊伍裡有人跟著笑。笑聲不大，但很刺。

Debug 博士低頭看自己的球鞋，鞋尖磨得發白。三十六小時沒闔眼，眼睛乾得像剛從烘碗機拿出來的玻璃杯。

「我們來 debug 一下，」他很小聲地自言自語，「Bug 不會自己消失……」

「你在唸什麼？」阿伯問。

「沒事，」他抬頭，「排隊。」

早上八點半，他穿著一件普通到不行的深藍色連帽外套，胸前別著一隻小瓢蟲徽章，站在中正區某個投票所外的隊伍裡。

前面是一位滿頭白髮的老伯，手裡捏著投票通知單，捏得像在捏一張彩券。

「少年仔，」老伯回頭，「你覺得今天會下雨嗎？」

「不會吧，」他抬頭看天，「雲都散了。」

「嘿啊，」老伯滿意地點頭，「我昨天看氣象，說今天放晴。不過啊，我現在看新聞都會多問一句——」

「真的假的？」

老伯眼睛一亮：「你也會喔！」

「會啊，職業病。」

「什麼職業？」

「呃……抓假的。」

「喔，警察喔？」

「……差不多。」

「啊你剛剛被那個阿伯虧，」老伯壓低聲音，「我跟你講，那種人就是出一張嘴。你昨晚那個照妖鏡，我孫子有教我按，很好用捏。」

「真的假的？」這次換Debug 博士問。

「真的啦！」老伯從口袋掏出一張摺得爛爛的紙，「你看，我孫子印的，一步一步教，我現在是我們里第一個會用的。」

紙上歪歪扭扭印著截圖，還用紅筆圈起來，寫著「按這裡」。

Debug 博士盯著那張紙，喉嚨忽然有點緊。

「阿伯，」他說，「你這個可以借我拍一張嗎？」

「拍啊拍啊，」老伯得意地挺胸，「我孫子說這個叫什麼……開源？對啦，開源，大家都可以用。」

隊伍往前動了一格。後面那個穿競選背心的阿伯，忽然不講話了。

投票所外面，他遇到了秀蘭嬤。

阿嬤今天穿了一件棗紅色的外套，頭髮梳得整整齊齊，牽著一個大概國小三年級的小孫子，祖孫倆站在門口曬太陽。

「阿凡！」秀蘭嬤一眼就認出他，笑得眼睛都瞇起來，「你嘛來投票喔？」

「對啊，剛投完。阿嬤你帶孫子來？」

「嘿啊，」阿嬤拍拍孫子的頭，「帶他來看看，什麼叫做自己選。」

小孫子仰頭：「阿嬤，為什麼要自己選？」

「因為別人的話不能亂信啊，」阿嬤理直氣壯，「要自己看、自己想、自己決定。」

Debug 博士愣了一下。

阿嬤轉頭看他，神氣地挺起胸膛：「我跟你講，我現在看新聞，都會先問一句『真的假的』。昨天那個什麼影片，我一看就覺得怪怪的，那個人的眼睛眨得太慢了。」

「阿嬤你現在是專家了。」

「什麼專家，」阿嬤擺手，「就是被騙過一次，學乖了。」

她說得很輕，像在講別人的事。但他知道，前世的那一支「Debug 博士推薦投資」的深偽影片，騙走的不只是她的退休金，還有她對所有畫面的信任。

那一夜之後，她再也不看電視。

「阿嬤，」他忽然說，「對不起。」

「為什麼要說對不起？」阿嬤瞪他，「又不是你騙我的。而且啊，」她拍拍他的手臂，「你這次做得很好。我那些老朋友，現在群組裡傳什麼，都會先丟去那個……那個什麼鏡？」

「照妖鏡。」

「對啦，照妖鏡。丟進去，紅色的就不要再傳。很好用欸，比我孫子還好用。」

小孫子在旁邊抗議：「阿嬤！」

「實話實說啦。」

「阿嬤，」小孫子忽然插嘴，「那我以後看到奇怪的影片，也可以丟照妖鏡嗎？」

「可以啊，」阿嬤蹲下來，跟他平視，「但是你要先問自己一句話。」

「哪一句？」

「『這是真的，還是有人想叫我生氣？』」

小孫子想了一下，用力點頭：「懂了。」

Debug 博士站在旁邊，忽然覺得，這比他做過的任何一支影片都還要有用。

手機震了一下。

林曉晴的訊息：

「你知道最好笑的是什麼嗎？今天群組裡最多人轉傳的，是查證連結。」

他站在投票所外的樹蔭下，回了一個笑臉。

下一則又來：

「以前大家轉傳的是假消息，現在轉傳的是『怎麼查假消息』。我剛剛還收到我阿姨傳來的照妖鏡使用教學，她自己做的圖文，做得很醜，但很用心。」

「醜沒關係，」他回，「有用就好。」

「她還問我，這個是不是可以拿去教里長。」

「可以啊，開源就是這樣用的。」

「程一凡，」林曉晴停了一下才回，「我以前很討厭政治人物。」

「我知道。」

「現在還是有一點。」

「……謝謝喔。」

「但是，」她又補了一句，「我現在知道，有些人是在 debug 民主，不是在演民主。」

他看著那行字，忽然覺得眼睛有點酸。可能是三十六小時沒睡的關係。一定是。

「不同立場，也能一起 debug，」他回，「這句話是妳說的。」

「對啊，」林曉晴回，「我今天投完票，要去幫我媽買菜。她說今天晚上要煮火鍋，慶祝『假消息死光光』。」

「幫我跟阿姨說，火鍋料要買真的。」

「她會說：『我現在都會問真的假的。』」

中午，Kevin 發了一篇長文。

標題很長，長到他滑了兩次才看完：「關於我曾經嘲笑技術召集人是超級外行這件事，我想說一些話」。

內容大意是：他錯了。他以前覺得「查證」很無聊、很慢、很不流量。他以前覺得「打假」是政治人物作秀。但那天晚上，他看到三萬多人在線上一起查證，看到阿嬤們在群組裡互相提醒，看到一個國小三年級的小孩問「為什麼要自己選」，他忽然覺得，自己這幾年做的影片，好像少了什麼。

「所以我決定，」他寫，「把這個月的業配收入，全數捐給防詐團體。不多，但這是我能做的。以後我的影片，每一支都會附上查證連結。如果大家覺得這樣很無聊，那也沒關係。無聊總比被騙好。」

下面留言一片：「Kevin 長大了」「這才是百萬訂閱該做的事」「我以後不酸你了」。

Debug 博士按了一個愛心。

下午，賈仁義接受訪問。

記者問他：「賈先生，您之前說『AI 不會騙人，會騙人的是人』，現在還這麼認為嗎？」

賈仁義沉默了三秒。

「我還是這麼認為，」他說，語氣比平常慢，「但我要補一句——正因為人會騙人，所以人更要誠實。AI 只是鏡子，鏡子照出什麼，是我們自己的臉。」

「所以您覺得這次事件，對台灣的 AI 發展有什麼啟示？」

「啟示就是，」賈仁義推了一下眼鏡，「我們不能只教 AI 怎麼變強，要教人怎麼變聰明。還有，」他頓了一下，「我以後不會再隨便說自己是教父了。教父會保護大家，我這次沒保護好。」

這段話後來被做成很多迷因。但Debug 博士覺得，這是賈仁義這輩子講過最誠實的一段話。

傍晚，開票時間。

聯盟辦公室裡，大家擠在電視前面，氣氛緊繃得像拉滿的弓。阿凱站在最前面，手裡捏著一杯已經冷掉的珍奶，吸管咬得扁扁的。

「老師，快來看，第一波數字要出來了！」

Debug 博士看了一眼，悄悄往後退，推開門，走了出去。

「老師？」阿凱追出來，「你不看結果？」

他回頭，笑了一下。

「結果是台北市民的事。」

「啊？」

「我的事，」他把手插進帽 T 口袋，「是讓這一次的選擇，是他們自己做的。」

阿凱愣在原地，珍奶還捏在手裡。

「可是……可是大家會想知道你怎麼看啊。」

「我怎麼看不重要，」他說，「重要的是，今天有沒有一個人，是因為被騙才去投的。如果沒有，那這一票，就是他自己投的。」

「……老師，你講話可以再文言一點沒關係。」

「快去裡面看，」他揮手，「幫我注意有沒有奇怪的訊息在群組裡流傳。」

「今天投票日欸，誰敢傳？」

「就是有人敢，才要有人看。」

阿凱翻了一個白眼，但還是乖乖回去了。

巷口的滷肉飯攤，今天有開。

秀蘭嬤的攤子，投票日也照常營業。她說：「肚子餓的人不分黨派。」

Debug 博士在塑膠椅上坐下來。

「阿嬤，兩碗。」

「兩碗？」阿嬤抬頭，「你一個人吃兩碗？」

「一碗給人。」

「誰？」

他沒回答，只是把另一碗放在對面的空位上。

熱氣慢慢升起來，又慢慢散掉。路燈亮了，巷子裡飄著醬油和油蔥的香味。

「哥，」他很小聲地說，「這碗是滷肉飯。有肥有瘦，上面有香菜，旁邊有醃蘿蔔。我知道妳吃不到，但還是幫妳點了。」

沒有回應。

眼鏡上，什麼都沒有。

「妳說妳最大的遺憾是吃不到滷肉飯，」他繼續說，「我想說，至少讓妳聞一下。雖然妳應該聞不到。」

熱氣繼續散。

「今天的台北，放晴了。」他低頭扒了一口飯，「沒有深偽之夜。沒有人被騙。阿嬤的孫子問她為什麼要自己選，她說因為別人的話不能亂信。」

他嚼了嚼，吞下去。

「妳教我的，」他說，「查證不是為了贏，是為了讓大家都能自己選。」

巷子裡很安靜。遠處隱約傳來辦公室那邊的歡呼聲，但他沒有回頭。

「結果怎樣，我都沒關係，」他說，「重要的是，今天大家投的，是真的。」

他吃完第一碗，把第二碗的熱氣又看了一下。

「好啦，」他站起來，把錢放在桌上，「我吃飽了。妳……妳好好休息。」

他走出巷口的時候，手機忽然震了一下。

他低頭看。

不是訊息。是眼鏡。

鏡片的角落，閃過一個極淡的像素。

像有人在眨眼。

只有一瞬間，比路燈的反光還短。但他看見了。

Debug 博士站在原地，愣了三秒。

然後他笑了。

「晚安，艾莉絲，」他說，「明天見。」

他轉身要走，眼鏡上忽然又閃了一下——這次不是眨眼，是一行極淡、淡到幾乎看不見的字，像用最後一格電量擠出來的：

`【哥，那碗……有香菜嗎？】`

巷口的風把滷肉飯的熱氣吹散。台北的夜，慢慢亮了起來。

  • 一定要帶國民身分證，健保卡、駕照不能代替；身分證遺失要先到戶政事務所補辦。
