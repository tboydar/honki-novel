「別管它，讓它飛。」

這句話讓整間辦公室的空氣瞬間凝固。說話的是聯盟裡一位立場鮮明的志工，他盯著手機上那支瘋傳的假錄音，嘴角竟然上揚。「反正燒的不是我們這邊，這對我們有利。」

Debug 博士把焊到一半的電路板放下，烙鐵還冒著煙。

十一月的台北，深夜十一點四十七分。桌上三杯超商咖啡，兩杯冷掉，一杯根本沒開封。他盯著螢幕上的開源模型訓練曲線，圓框眼鏡片上跳著艾莉絲的迷你全息影像。她正盤腿坐在他視線右上角，像個在夜市板凳上等鹽酥雞的少女，帽 T 的袖子長到蓋住手指。

「哥，你這條曲線比你前世那次相親的進展還平。」

「我什麼時候去相親了？」

「二〇四三年啊，對方研究量子材料，你們聊了四十分鐘散熱問題。」

「……那段記憶我寧願被吃掉。」

話才說完，桌上六支手機同時震動，像一群被踩到尾巴的電子雞。群組訊息以每分鐘四十則往上衝，貼圖、語音、驚嘆號，還有長輩圖等級的「緊急！快看！」。

阿凱從沙發彈起來，頭髮像被靜電打到。「程博士，出事了。」

「哪一種出事？」

「對手陣營的候選人，被爆出一段錄音。」阿凱把手機轉過來。「內容我不用念，反正就是那種一句話就能毀掉一個人的假話。」

錄音品質刻意做得很差，像隔著一道牆偷錄。聲音學得極像，連說話時習慣性的停頓都抓到了。Debug 博士只聽八秒，按下暫停。

「假的。」

「你這麼確定？」

「背景有捷運進站音樂。」他推了推眼鏡。「但錄音裡說的時間，當事人正在另一場公開活動，好幾家媒體都有直播畫面。做假的人忙著學聲音，忘了學行程。」

然後，那位志工笑了。

「這對我們有利啊。」他壓低聲音，笑得像撿到錢。「別管它，讓它飛。反正燒的不是我們家。」

「對啊，」另一個接話，「我們什麼都不做，就是最大贏家。」

空氣裡有一種很微妙的氣味，不是咖啡，是那種「別人的災難剛好是我的運氣」的竊喜。

Debug 博士站起來。

他沒有大吼，只是把桌上那杯沒開封的咖啡，「啪」地一聲放平在桌面。力道不大，但整間辦公室瞬間安靜。

「你們剛剛那句話，」他慢慢轉頭，眼神像在 debug 一段爛程式碼，「我前世的台北，聽了三十五年。」

「程博士……」

「深偽今天打他，明天就打我們，後天打的是全台北。」他一個字一個字說。「我們守護的是選舉，不是輸贏。」

那位志工還想辯：「可是這是對手的災難耶，我們不出手也……」

「你現在覺得是災難。」Debug 博士打斷他。「等到有一天，有人用我的臉、用你母親的名字做一支影片，你還會覺得『讓它飛』很好玩嗎？」

沒人講話。那位志工低下頭，把手機收進口袋，耳根紅了一片。

「我們來 debug 一下。」他拿起手機。「這個社會的 bug，不是哪一個陣營說謊，是我們開始覺得『反正不是我被騙』就沒關係。這個 bug 不修，二〇六一年我們全都會被它吃掉。」

他轉頭。「曉晴呢？」

「我在。」

林曉晴站在門口，外套都還沒脫，肩上背著一台筆電，眼睛底下有熬夜的黑眼圈，但眼神很亮。她原本是最瞧不起政治人物的那種人，這一個月卻天天睡在聯盟的沙發上。

「照妖鏡的檢測流程，妳熟。」Debug 博士說。「我們連夜跑。」

「跑完之後呢？」

「公開。」他說得毫不猶豫。「報告公開給所有媒體、所有事實查核機構，一份不留。還有，」他停了一下，「聯絡對手陣營，問他們要不要技術協助。」

整間辦公室像被按下靜音鍵。

「程博士，」阿凱小心翼翼地問，「你確定？幫對手？」

「我確定。」他已經在捲袖子。「選舉是一場比賽，但比賽的規則不能被拆掉。今天有人拆對手的球門，明天就會來拆我們的。我們要守的不是球門，是球場。」

林曉晴看了他兩秒，然後笑了。

「好。」她把筆電放上桌。「那我先講清楚，我還是很討厭政治人物。」

「我知道。」

「但你今天這句話，」她坐下，手指已經在鍵盤上飛，「我記下來了。」

凌晨一點十二分，照妖鏡跑完第一輪。

【叮！偵測到合成語音，真實度：4.7%】
【關鍵特徵：背景音時序錯置、呼吸週期規律化、語尾共振峰異常】

「四點七趴。」阿凱吹了聲口哨。「這比我大學微積分的出席率還低。」

「你微積分被當兩次，出席率是零。」Debug 博士頭也不抬。

「你不要在這種時候補刀好不好。」

艾莉絲在他視線角落舉手。「哥，我比對了一千三百二十七支前世檔案，這個合成引擎的手法，跟二〇二六年十一月二十七號那批是同一套。只是這次是測試版。」

Debug 博士的手指停了一下。

「測試版？」

「嗯。」艾莉絲難得沒有用夜市腔，聲音低了半度。「他們在練兵，哥。這支錄音不是要毀掉那個人，是要看我們會不會上鉤。」

辦公室裡沒人聽得到艾莉絲，但 Debug 博士的表情變了。他盯著螢幕上那條 4.7% 的真實度曲線，像盯著一張病危通知。

「那就更不能讓它飛。」他說。

凌晨三點，報告出爐。十一頁，全中文，圖表清楚到連阿嬤都看得懂。每一項異常特徵都附上時間軸、頻譜圖，還有「如何自己檢查」的簡單步驟。最後一頁只有一行字：

「這支錄音是假的。但下一個被做成假的，可能是你認識的人。」

他按下寄出。收件人：十二家媒體、四家事實查核機構，還有對手陣營的公開聯絡信箱。

「寄了。」林曉晴說。

「寄了。」他回。

凌晨三點四十一分，一支不具名的號碼傳了訊息進來。

「我是對手陣營的幕僚，年輕的那個，你不認識我。我只想說：謝謝。我沒想到會是你們。」

Debug 博士看著那行字，看了很久。

他回：「修 bug 這種事，需要我們都在。」

對方隔了兩分鐘，回了一個字：「好。」

然後又補一句：「你們的報告寫得比我們的清楚。有點丟臉。」

他笑了，回：「那下次換你們寫，我們抄。」

天亮之後，網路炸了。不是因為錄音，是因為那份報告。

「不分立場都該看」變成一個轉傳標籤，從科技圈傳到媽媽社團，從媽媽社團傳到計程車行的群組。有人截圖他那句「我們守護的是選舉，不是輸贏」，做成圖卡，背景還是萬華夜市的燈籠。

當然，也有人罵。

「吃裡扒外。」

「政治變色龍。」

「幫對手洗白，是不是收了什麼好處？」

阿凱滑著留言，氣到差點把手機丟出去。「程博士，這些人……」

「讓他們罵。」Debug 博士正在剝一顆茶葉蛋，語氣平靜得像在報天氣。「被罵不會少一塊肉。但如果有阿嬤因為這份報告，以後看到影片會多懷疑三秒，那就夠了。」

「三秒？」

「三秒就夠了。」他把蛋黃吃掉。「詐騙靠的是你來不及想。你多想三秒，它就少三秒的成功率。」

林曉晴從筆電後面探出頭。「你這個人真的很奇怪。」

「哪裡奇怪？」

「你明明可以什麼都不做，撿現成的便宜。」她說，「但你偏偏選最麻煩的那條路。」

「因為最麻煩的那條路，」他推了推眼鏡，「通常是唯一正確的那條。」

艾莉絲在他視線角落，安靜地看著這一切。她的全息影像比平常淡了一點，像訊號不穩的電視。

「哥。」

「嗯？」

「前世沒有這一段。」她的聲音有點飄。「我翻遍檔案，二〇二六年的十一月十四號，這一天，沒有人公開那份報告。那支錄音飛了三天，等到終於被證明是假的，已經沒有人在乎真假了，然後……」

「然後什麼？」

「然後就沒有人再相信任何人了。」她說。「哥，我們在改寫歷史耶。」

Debug 博士放下茶葉蛋的殼，看著窗外。台北的早晨正在醒來，捷運的列車聲從遠方傳來，早餐店的鐵板滋滋作響。

「那就對了。」他說。「我們在改寫歷史。」

他話才說完，手機又震了一下。

不是群組，不是媒體，是一則加密訊息。寄件者欄位空白，只有一個字。

「——莫」

Debug 博士的手指僵在半空。

訊息只有兩行：

「好玩嗎？三十三天倒數，我會讓你的照妖鏡，照出一個沒有人相信的城市。」

「——莫」

辦公室的空氣瞬間結冰。

阿凱湊過來看，臉色發白。「程博士，這個莫……」

「鏡淵的莫無影。」Debug 博士把手機放下，聲音很輕，卻很穩。「他來了。」

林曉晴站起來。「那我們怎麼辦？」

Debug 博士看著窗外，看著這座他死過一次、又回來一次的城市。他想起前世那個沒有人相信任何畫面的台北，想起秀蘭嬤那雙再也不看螢幕的眼睛。

「怎麼辦？」他笑了一下，笑得有點狠。「照妖鏡照妖，他出招，我們拆招。」

他轉頭。眼鏡片上，艾莉絲已經站直了身體，帽 T 的袖子還是太長，但眼神很亮。

「哥，」她說，「這次我不會讓你一個人。」

「我知道。」他拿起那杯終於開封的冷咖啡，一口氣喝掉半杯。「因為這次，我們有三十三天，還有整個台北。」

他放下杯子。

「這座城市的 bug，」他說，「從今天開始修。」

窗外，太陽升起來了。

但所有人都知道，真正的黑夜，還沒來。

——因為那則加密訊息的最後，還有一行極小的字，小到 Debug 博士剛才差點漏看：

「順帶一提，你阿嬤的滷肉飯，我吃過。很好吃。」

Debug 小教室選罷法怎麼管深偽？

  • 《公職人員選舉罷免法》第 104 條：意圖使候選人當選或不當選，散布謠言或傳播不實之事，足以生損害於公眾或他人者，處五年以下有期徒刑。
  • 同條第二項：如果是用候選人本人的深度偽造聲音、影像來犯這個罪，處七年以下有期徒刑；意圖營利者，加重其刑至二分之一，並得併科新臺幣二百萬元以上一千萬元以下罰金。
  • 法律所稱「深度偽造」，是指以電腦合成或其他科技方法製作本人不實之言行，並足使他人誤信為真之技術表現形式；在選舉期間，候選人發現自己的深偽影音被刊播，可以向警察機關申請鑑識。
  • 給一般人的提醒：轉傳也可能構成「散布」。不確定真假的選舉訊息，不要轉；看到了，可以向平台檢舉，或交給事實查核機構。
