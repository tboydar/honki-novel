阿嬤的電話：您的孫子出事了

時間：2026 年 10 月 29 日

一分鐘爽讀8 格漫劇分鏡，先爽再讀

「阿嬤！我撞到人了！快救我！」

這一聲哭喊，從秀蘭嬤那支音量開到最大的老手機裡炸出來，整條萬華巷口都聽見了。

Debug 博士的筷子停在半空中，滷肉飯的湯汁滴回碗裡。

「你講什麼？車禍？」秀蘭嬤的手一抖，手機差點掉進湯鍋，「阿宏？是阿宏嗎？」

「阿嬤，我現在在警察局外面……」電話那頭的少年哭得上氣不接下氣，「對方說要三十萬和解，不然要告我……阿嬤，妳不要跟我爸媽講，他們會打死我……」

Debug 博士放下筷子。

那個聲音，有夠像。哭腔、換氣、那個「阿嬤」尾音上揚的撒嬌，一模一樣。

如果不是他這輩子聽過幾萬支深偽音檔——

【叮！偵測到語音複製詐騙。聲紋與真實親屬樣本高度吻合。AI 合成機率：99.2%。】

螢光黃的提示框在他眼前展開，字體像夜市價目表。

半透明的金髮少女全息影像從他對面的塑膠椅跳起來，帽 T 的帽子滑到背後。

「哥，這是合成的。樣本大概十幾秒就夠了，品質中等——但對阿嬤這款年紀的人來說，聽不出來啦。」

「三十萬……」秀蘭嬤喃喃自語，人已經站起來了，「阿宏你等我，阿嬤去郵局領錢，你不要怕——」

「阿嬤！」Debug 博士伸手按住她的手臂。

「阿凡你別攔我，那是我孫子！」

「阿嬤，」他的聲音很輕，很穩，「我問妳一個問題。妳跟阿宏，有沒有講過只有你們兩個知道的事？」

秀蘭嬤愣住。

「有啦……他小時候，我都叫他……」

「那妳問他。」

Debug 博士把手機接過來，按下擴音。

「阿宏啊，」秀蘭嬤的聲音在抖，「你講，阿嬤平常都叫你什麼？」

電話那頭沉默了半秒。

「……阿嬤，現在是什麼時候了，妳還在問這個？」

「你講啊。」

「我現在很急耶！對方在瞪我了！」

「你講出來，阿嬤馬上領錢。」

又是一陣沉默。這次比較長。

「……秀蘭嬤。」

Debug 博士挑眉。

對方居然直接叫「秀蘭嬤」。

「你叫我什麼？」秀蘭嬤的聲音突然尖了起來。

「阿嬤啊！妳是阿嬤啊！妳怎麼這麼囉嗦！」

「你不是阿宏。」秀蘭嬤的手抖得更厲害了，「阿宏叫我『阿嬤』，但他從來不會叫我『秀蘭嬤』。你這個騙子——」

「老太婆！」電話那頭的聲音突然變了，哭腔整個消失，換成一個粗暴的男聲，「我告訴妳，妳孫子現在在我們手上，妳不領錢，他就斷一條腿！妳聽懂沒有？」

秀蘭嬤整個人往後退，撞到椅子。

Debug 博士扶住她，順手把手機撈回來。

「喂？喂喂喂？那個……少年仔？」

電話那頭頓了一下。

「你誰？」

「我喔？」Debug 博士推了推眼鏡，聲音突然變得又慢又憨，「我是阿嬤的鄰居啦，姓程，大家都叫我程桑。少年仔，你剛剛講那個三十萬，是現金還是匯款啊？」

「……現金。」

「現金喔？啊現金要去哪裡領？郵局嗎？還是農會？我們萬華這邊有一間農會，可是下午四點半就關了耶。」

「你叫那個老太婆聽電話！」

「她現在在找存摺啦，」Debug 博士語氣超誠懇，「少年仔你不要急，我跟你講，阿嬤的存摺都放在米缸裡面，她現在在挖米，挖得滿地都是，你等一下嘿。」

艾莉絲在他耳邊憋笑憋到整個人發光。

「哥，你這招好壞。」

「閉嘴，幫我追蹤。」

「已經在追了，訊號跳了三個基地台，對方有防追蹤。給我九十秒。」

電話那頭已經開始不耐煩：「你叫那個老太婆快一點！」

「快到了快到了，」Debug 博士繼續演，「對了少年仔，我問你喔，你們那個人被撞得嚴不嚴重啊？有沒有叫救護車？健保卡有沒有帶？」

「關你什麼事！」

「哎唷，問一下而已嘛。啊如果和解的話，是不是要簽什麼和解書？要不要蓋章？我跟你講，我們萬華這邊有一個代書，姓陳，他蓋章很便宜，一次兩百塊——」

「你不要再廢話了！」

「好啦好啦，」Debug 博士嘆了一口氣，「啊不然這樣，少年仔，你人在哪裡？我陪阿嬤把錢送過去，比較安全啦。你講一個地點。」

電話那頭沉默了。

Debug 博士可以感覺到，對方在盤算。

「……龍山寺捷運站，三號出口。」

「好喔，龍山寺三號出口，」Debug 博士點頭，「我們大概二十分鐘到。少年仔你穿什麼顏色的衣服？我認一下。」

「你來就知道了。」

「哎唷，你講一下嘛，不然我認錯人怎麼辦？我跟你講，我這個人臉盲很嚴重，上次在夜市把我老婆認成賣蚵仔煎的——」

「黑色外套！快點來！」

電話掛了。

Debug 博士放下手機，臉上的憨笑瞬間收乾。

「艾莉絲。」

「追到了。發話位置在板橋，但車手會移動。訊號軌跡已經丟給阿凱了。」

「阿凱？」

耳機裡傳來一個嘴砲的聲音：「老師，我剛剛全程都有聽到。你演那個程桑演得有夠像，我差點以為你真的有老婆。」

「少廢話，165 打了沒？」

「打了，也報警了。萬華分局說會派人過去龍山寺三號出口埋伏。」

「好。」Debug 博士轉頭看向秀蘭嬤。

阿嬤坐在塑膠椅上，整個人像被抽空了一樣，手還緊緊抓著那本從米缸挖出來的存摺。

「阿凡……」她的聲音很小，「那真的不是阿宏喔？」

「不是。」

「可是聲音……聲音一模一樣耶。」

「阿嬤，」Debug 博士蹲下來，跟她平視，「現在的科技，可以複製一個人的聲音。十幾秒就夠了。」

秀蘭嬤的眼淚突然掉下來。

「我剛剛真的要去領錢耶……我想說，那孩子從小就是我帶大的，他出事，我怎麼可能不去……」

「我知道。」

「我如果領了，三十萬就沒了……那是我要留給阿宏娶某的錢……」

Debug 博士握住她的手。

那雙手，前世他沒能握住。

「阿嬤，錢還在。妳的錢還在。」

二十分鐘後，龍山寺捷運站三號出口。

一個穿黑色外套的年輕人站在騎樓下，低著頭滑手機，腳邊放著一個帆布包。

他看起來大概二十出頭，頭髮染成金色，耳朵上掛著無線耳機。

便衣警察從三個方向靠近的時候，他甚至還沒反應過來。

「先生，麻煩你配合一下。」

「幹嘛？我又沒怎樣！」

「涉嫌詐欺，請你跟我們走一趟。」

年輕人被壓在牆邊的時候，還在嘴硬：「你們有證據嗎？我只是在這裡等人耶！」

Debug 博士站在對街，隔著馬路看這一幕。

他沒有過去。

他只是推了推眼鏡，靜靜地看著。

車手被押上警車前，突然抬起頭，視線穿過馬路，直直落在 Debug 博士身上。

那一瞬間，年輕人的表情變了。

不是害怕，是一種很奇怪的、近乎嘲諷的平靜。

「喂，」他朝 Debug 博士的方向喊，「你以為抓到我有用喔？」

警察推了他一把：「閉嘴。」

「我們老闆有十萬張臉啦！」年輕人被塞進車裡前，回頭笑了，「十萬張！你抓得完嗎？」

車門關上。

警車開走。

Debug 博士站在原地，風從龍山寺那邊吹過來，帶著一點線香的味道。

「十萬張臉……」

「哥。」艾莉絲的聲音難得沒有笑意。

「我知道。」他低聲說，「鏡淵。」

那天晚上，秀蘭嬤的攤子提早收了。

她坐在塑膠椅上，腿還在軟，手裡捧著一碗 Debug 博士硬塞給她的熱湯。

「阿凡，」她突然開口，「你怎麼知道要問暗語？」

Debug 博士頓了一下。

「……我教的啊。我之前不是有跟妳講，接到奇怪的電話，要先問只有家人知道的事情？」

「有啦，你有講過。」秀蘭嬤點點頭，「可是我今天一緊張，整個人都忘了。」

「正常。人都會忘。」

「還好有你。」秀蘭嬤伸出手，緊緊握住他的手，「阿凡，還好有你。」

那雙手很粗糙，是幾十年洗碗、切滷肉、數零錢留下來的粗糙。

Debug 博士低下頭。

前世的畫面突然湧上來——

同一雙手，在 2059 年的騎樓下，握著一張被騙光的存摺，抖得比今天還厲害。

那時候的她說：「阿凡，我看電視上那個明明就是你啊。你跟我說那個投資很好……我就在想，你是我的學生，你怎麼會騙我……」

「可是那個畫面那麼清楚……聲音也是你的……」

「阿凡，我現在，再也不知道要相信什麼了。」

Debug 博士的眼眶紅了。

「阿嬤，」他的聲音有點啞，「以後不管看到什麼、聽到什麼，妳先打給我。我幫妳看。」

「好啊。」秀蘭嬤笑了，「啊你技術召集人不是很忙？」

「再忙，」Debug 博士說，「也要接阿嬤的電話。」

回程的車上，艾莉絲的全息影像坐在副駕駛座，抱著膝蓋，安靜了很久。

「哥。」

「嗯？」

「我調了檔案。」

Debug 博士握著方向盤的手緊了一下。

「2061 年的歷史資料庫裡，有一條紀錄。」艾莉絲的聲音很輕，「2026 年 10 月 29 日，台北市萬華區，首次出現語音複製詐騙通報。受害者：女性，七十八歲，小吃攤商。」

「……然後呢？」

「然後，這通電話，被標記為鏡淵集團的『第一次田野實驗』。」

車子停在紅燈前。

Debug 博士看著前面的紅燈，一句話都沒說。

「哥，」艾莉絲抬起頭，藍色的眼睛在夜色裡發亮，「前世，這通電話，是他們測試技術的開始。」

「今世，」Debug 博士慢慢開口，「是我們第一次，把他們的手打回去。」

綠燈亮了。

車子往前開。

「艾莉絲。」

「嗯？」

「幫我查一件事。」

「查什麼？」

「鏡淵的『十萬張臉』，」Debug 博士推了推眼鏡，「到底是從哪裡來的。」

【叮！查詢權限不足。建議提升算力等級。】

「那就提升。」

【警告：提升算力將消耗大量資源。是否確認？】

Debug 博士看著前方的路，沒有猶豫。

「確認。」

夜色裡的台北，燈火一路延伸到天邊。

三十三天，還有三十三天。

他不知道的是，這一次確認，會在很久以後，讓他忘記一個很重要的人。

但他現在，只想先守住這條巷口。

Debug 小教室防範「語音複製」詐騙

  • 現在的技術，只要幾秒鐘到幾十秒的聲音樣本，就可能合成出很像的聲音；公開影片、語音訊息、甚至一通「打錯電話」都可能被拿去當素材。
  • 約一個家庭暗語：只有家人知道的一句話，電話裡遇到「出事要錢」，先問暗語。
  • 掛掉，回撥：用你自己手機裡存的號碼回撥本人或其他家人確認，不要用對方給的號碼。
  • 不在電話裡匯款、不交付現金或提款卡：「不能跟家人說」「現在就要」都是典型話術。
