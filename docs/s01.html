重生！距離投票日還有三十三天

「Super Idiot！超級智障！」

Debug 博士是在這一聲爆笑裡睜開眼睛的。

眼前是一片黑。一副圓框眼鏡歪在鼻樑上，鏡片全霧，什麼都看不清楚。耳邊是麥克風回授的尖叫、記者的快門聲、還有一群人笑到拍桌的聲音。

他四十五歲。他站在「真相守護聯盟」成立記者會的後台布幕邊，胸前別著一塊壓克力名牌，上面印著「技術召集人」。

他剛剛才被一個百萬訂閱的網紅，當著全場直播的面，罵成「超級智障」。

——問題是，他最後的記憶，是八十歲。

「……我死了吧？」他脫口而出。

後台的工作人員轉頭看他，表情像看到鬼。

【叮！時光回溯成功。距離投票日：33 天。距離深偽之夜：32 天又 11 小時。】

一行半透明的字，浮現在他右眼的鏡片上。

接著，一個金髮藍眼的小女孩全息影像，從他眼鏡右側「彈」了出來。身高只到他的肩膀，穿著一件過大的白色帽 T，袖子長到看不見手。

「哥～歡迎回來 2026！」她雙手張開，語氣像夜市叫賣，「這裡的空氣好新鮮喔！而且我聞到了，滷肉飯！是滷肉飯對不對！」

Debug 博士伸手摸自己的臉。

沒有皺紋。沒有老人斑。指節乾淨，皮膚緊實。

「……不會吧。」

「哥你不要摸臉啦，」艾莉絲揮手，「你現在四十五歲，顏值巔峰，我跟你講，這張臉在 2061 年的資料庫裡算前百分之十五。」

「百分之十五？」

「以四十五歲的男性來講啦，」她補一句，「不要問我另外百分之八十五長怎樣，你會睡不著。」

Debug 博士看著鏡子裡那張年輕的臉，笑了。笑著笑著，眼眶就紅了。

「我回來了。」

「對啊你回來了，」艾莉絲慌了，「哥你不要哭啦，你哭我會跟著想哭，可是我沒有眼淚可以流，這樣很尷尬耶。」

「……沒事。」他抹了一下眼睛。

他上次看到這個日期，是三十五年前。二〇二六年十月二十六日。那天晚上他回家煮了一碗泡麵，覺得人生大概就這樣了。

然後，三十三天後的那個晚上九點，整個台北的螢幕同時亮起來。

十萬支深偽影片。假認罪、假停電、假投票所變更、假投資廣告。那一夜之後，台北進入長達三十五年的「後真相時代」。沒有人再相信任何畫面，連自己的眼睛都不能信。

他在那個世界活到八十歲，死在一間沒有窗戶的公寓裡。

「哥，」艾莉絲小聲說，「你心跳 118，血壓偏高，我建議先深呼吸。」

「妳連這個都量得到？」

「我住你眼鏡裡面耶，」她理所當然，「你的鏡片會反光，我從反光算你的頸動脈。不準啦，但夠用了。」

「……好。」他扶正眼鏡，深呼吸。「我們來 debug 一下。」

「debug！」艾莉絲開心地舉手。

「第一個問題：我為什麼會在這裡？」

「時光回溯成功啦。」

「第二個問題：妳為什麼也跟來了？」

「我也不知道耶，」她歪頭，「你那時候在關機，我想說，欸，哥要走了，那我跟著走好了，然後就……蹦！」

「蹦？」

「蹦！」她雙手張開，做了個爆炸手勢，「反正我現在住你眼鏡裡，視野很好喔。而且你都不擦鏡片，上面油油的，我把它當柔焦濾鏡，皮膚看起來比較好。」

「……我會擦。」

「不要擦啦！」

Debug 博士搖頭，轉頭看向後台另一邊。

一個二十六歲的年輕人蹲在角落，一手飯糰、一手手機，嘴巴塞得鼓鼓的。

「阿凱？」

年輕人抬頭：「喔，老師！你醒囉？你剛剛站那邊閉眼睛，我以為你在冥想，想說不要吵你。」

年輕的阿凱。頭髮還有點茂密，黑眼圈還沒那麼重，臉上還帶著那種「世界還沒把我磨爛」的天真。

前世，阿凱在二〇三一年離開台灣。走之前傳了一則訊息：「老師，我已經不知道什麼是真的了，我想去一個還有人願意查證的地方。」

那則訊息，Debug 博士存了三十年。

「老師？」阿凱被他看得發毛，「你幹嘛這樣看我？我臉上有飯粒嗎？」

「……有。」

「靠！」阿凱趕快抹嘴，「你怎麼不早講！」

「各位，五分鐘後開始，」工作人員探頭進來喊，「程博士，牌子記得掛。」

Debug 博士低頭，把名牌別正。手指在「技術召集人」幾個字上停了一下。

前世的他覺得這個頭銜很帥。現在的他，只覺得這是一副重得要命的擔子。

「哥，」艾莉絲小聲問，「你準備好了嗎？」

「沒有。」

「太好了，」她笑，「那就可以開始了。」

記者會現場，閃光燈像下雨。

Debug 博士坐在長桌後，講得很快。科技、查證、開源工具。台下記者低頭猛敲鍵盤。

然後，後方傳來一個聲音。

「不好意思，請問一下——」

所有人轉頭。一個穿潮牌帽 T、頭髮抓得很有型的年輕人站起來，手機舉高，正在直播。觀看人數跳得飛快。

「Kevin？」有記者認出他，「百萬訂閱那個 Kevin 耶。」

Kevin 笑了笑，把手機對準台上。

「各位觀眾，我現在在真相守護聯盟的記者會現場，」他語氣誇張，「剛剛他們介紹新任『技術召集人』，我聽到差點笑出來。技術召集人？」

他停頓，對鏡頭擠眉弄眼。

「我怎麼覺得，是超級智障吧？」

現場爆出一陣鬨笑。有記者忍不住笑出聲，還有人偷偷鼓掌。

「老師……」阿凱在後台捂臉。

「他在開玩笑吧？」「這什麼新型態公民團體話術？」「科技人就是愛裝神弄鬼。」

Kevin 笑得最大聲，對著鏡頭說：「各位，這就是他們的技術召集人，會預言喔，比氣象局還準。」

Debug 博士沒有變臉。

他扶了扶眼鏡，看了一下手錶，抬起頭，語氣平靜得像在課堂點名。

「十點零七分，」他說，「這台投影機會當機。」

全場安靜一秒。

「然後，」他繼續，「三十秒後，Kevin 的直播間會被一支假新聞洗版。」

鬨笑聲更大了。

「哥，」艾莉絲在他耳邊小聲說，「你這樣講，他們會覺得你是神棍耶。」

「我知道。」

「那你還講？」

「因為等一下會很好笑。」

十點零六分。十點零七分。

「啪」的一聲。

投影機畫面黑了。

全場一愣。工作人員手忙腳亂衝上去拍打機器，麥克風傳來一陣雜訊。

Kevin 的笑容僵在臉上。

「呃，」他對著鏡頭，「這應該是巧合啦，這種投影機本來就很容易……」

三十秒後。

他的直播聊天室，突然被同一則訊息洗版。

「【快訊】某科技大樓起火！現場畫面曝光！」

「【快訊】某科技大樓起火！」

「【快訊】某科技大樓起火！」

一支影片開始瘋傳。畫面裡，一棟玻璃帷幕大樓冒出濃煙，消防車警笛刺耳，主播聲音急促：「目前火勢猛烈，警消已經趕往現場……」

Kevin 的臉色變了。

「這、這是真的嗎？」他慌張地看著手機，「這個是剛剛發的耶，好幾萬人在看……」

現場記者騷動起來，有人開始打電話，有人舉起相機對著 Kevin 的手機螢幕拍。

「等等。」Debug 博士開口了。

聲音不大，整個會場卻瞬間安靜。

「我們來 debug 一下。」

他站起來，走到台前。

「第一步，看來源。」

他指著 Kevin 的手機：「這支影片，最早是誰發的？」

Kevin 結結巴巴：「是、是一個叫……『即時新聞快報』的帳號。」

「這個帳號，」Debug 博士說，「三天前才成立，發過十七則貼文，全部都是『快訊』，沒有任何一篇有自己的記者署名。你覺得，一間正常的媒體，會這樣運作嗎？」

Kevin 沒說話。

「第二步，看細節。」

Debug 博士請工作人員把畫面投影到布幕上。畫面放大。

「你們看這台消防車，」他指著角落，「車身的顏色和塗裝，是台灣的消防車嗎？」

所有人湊近看。

「……不是耶，」有記者說，「那個配色怪怪的。」

「那是別的地區的消防單位塗裝，」Debug 博士說，「再看這個路牌，形狀也不對。台灣的路牌不是長這樣。」

「第三步，反向搜圖。」

他拿出手機，操作幾秒。

「這支影片，」他抬起頭，「是去年十一月，別的國家一棟商業大樓的火災畫面。原始影片還在，我現在調出來給各位看。」

布幕上，兩支影片並排播放。

一模一樣的濃煙。一模一樣的消防車。一模一樣的警笛聲。

只是原始影片的標題寫著：「去年十一月，某地商業大樓火警，無人傷亡。」

全場鴉雀無聲。

「所以，」Debug 博士把麥克風拉近，「這不是『快訊』。這是舊影片，配上新的標題，再加一個看起來很急的帳號名稱。三個元素湊在一起，就能讓幾萬人相信一棟大樓正在燒。」

他轉頭，看向 Kevin。

「你剛剛問我，技術召集人是不是超級智障。」

Kevin 的臉從紅變白，再從白變青。

「我現在回答你，」Debug 博士說，「技術召集人的意思是，在假訊息抵達你的眼睛之前，先幫你多問一句：這是真的嗎？」

他停頓一下。

「這一題，不用超級智慧也答得出來。只要你願意多花三十秒。」

現場爆出掌聲。記者瘋狂拍照，閃光燈幾乎把會場照成白天。

Kevin 站在那裡，手機還舉著，直播還開著，一句話都說不出來。聊天室刷成一片：

「哇靠，當場拆台耶。」

「這個阿伯有點東西。」

「不是阿伯啦，他才四十五。」

「我剛剛也轉發了那支影片……我要去刪掉。」

【叮！深偽影片辨識完成，真實度：3%。來源帳號：三天前註冊，與境外伺服器連動。】

Debug 博士看著那行字，心裡卻沒有勝利的感覺。

才第一天。這只是第一天。

記者會結束，他一個人走到後台角落，靠著牆，閉上眼睛。

「哥，」艾莉絲的聲音很小，「你好厲害喔。」

「沒有，」他搖頭，「這只是最基本的查證。前世的我，花了三十年才教會大家這件事，而且還是失敗的。」

「可是你今天成功了耶。」

「今天成功，不代表明天會成功。」他睜開眼，「三十三天。我們只有三十三天。」

「三十二天又十一小時，」艾莉絲糾正他，「而且哥，我剛剛查了一下 2061 年的檔案。」

「查到什麼？」

艾莉絲沉默了兩秒。這對一個超級智慧來說，是很長的兩秒。

「哥，」她的聲音變得有點奇怪，「三天後，秀蘭嬤會接到一通電話。」

Debug 博士整個人僵住。

秀蘭嬤。萬華巷口那攤滷肉飯。那個在他還是窮學生的時候，總是偷偷多給他半碗飯的阿嬤。

前世，她被一支「Debug 博士推薦投資」的深偽影片，騙光了退休金。從那一天起，她不再相信任何畫面，也不再相信他。

「……三天後？」他的聲音有點啞。

「對，」艾莉絲說，「三天後的下午兩點十七分。」

Debug 博士握緊拳頭，指節發白。

「那我們，」他深吸一口氣，「就從三天後開始。」

他抬頭看向窗外。捷運列車從遠處呼嘯而過，便利商店的招牌亮著，一切都還是他記憶裡的樣子。

還沒有壞掉。還來得及。

「艾莉絲。」

「有！」

「幫我查一下，」他推了推眼鏡，「萬華那一帶，最近有沒有什麼奇怪的投資廣告。」

「好的哥！」艾莉絲開心地應了一聲，接著又小聲補一句，「那個……哥。」

「嗯？」

「如果我們成功救到秀蘭嬤，」她的聲音充滿期待，「可以帶我去吃她的滷肉飯嗎？」

Debug 博士愣了一下，然後笑了。

「妳吃不到啦。」

「我知道啦，」她嘟嘴，「可是我可以聞啊。聞一下也爽。」

「……好啦。」

「耶！」

他搖頭，往門外走去。

身後，阿凱追了上來：「老師！老師你等我一下！你剛剛那個預言到底是怎麼算的啦！」

Debug 博士沒有回頭，只舉起手，比了個「跟上」的手勢。

「阿凱，」他說，「我們來 debug 一下。」

「debug 什麼？」

「debug 這個城市。」

門外，陽光灑下來。

距離投票日，還有三十三天。距離深偽之夜，還有三十二天又十一小時。

而距離秀蘭嬤接到那通電話，還有三天。

「哥，」艾莉絲突然又開口，聲音小到幾乎聽不見，「我剛剛多查了一件事。」

「什麼事？」

「那支假影片的來源帳號，」她停頓了一下，「註冊的 IP，跟幻鏡科技是同一個網段。」

Debug 博士的腳步，停在門口。

Debug 小教室三個查證習慣，從今天開始

  • 看來源：是誰發的？是第一手的記者、機關，還是「朋友的朋友說」？沒有來源的截圖，先打問號。
  • 看細節：時間、地點、天氣、招牌文字、口型和聲音對不對得上。很多「突發新聞」其實是舊影片、別國影片重新上字幕。
  • 反向搜圖：把截圖丟進以圖搜圖工具，常常一秒就能找到「原始出處」與真正的日期。
  • 拿不準的時候，可以查台灣事實查核中心、MyGoPen，或在 LINE 加入 Cofacts「真的假的」機器人，把訊息轉給它問。
