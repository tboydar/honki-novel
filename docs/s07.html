「三千萬的公司，燒八千萬的算力，這不是新創，這是軍火商。」

林曉晴把那台筆電「啪」地轉過來，力道大到差點把咖啡震倒。二樓媒體室冷氣很強，她的額頭卻在冒汗。

Debug 博士才剛坐下，連椅子都還沒坐熱。

「妳不是說要給我看一樣東西？」他問。

「我給你看的是炸彈。」

螢幕上是一張密密麻麻的資金流向表。幻鏡科技，登記資本額三千萬，過去半年雲端伺服器費用換算下來，逼近八千萬。錢繞了三層海外空殼公司，最後全部匯進同一個帳戶。

「還有這個。」她滑到下一頁，聲音壓低，「這些空殼公司的登記地址，跟三年前幾起大規模個資外洩案，是同一批。」

Debug 博士的手指停在觸控板上。

「電話、聲音、照片，都是偷來的？」

「格式一模一樣。」林曉晴推了推眼鏡，「Debug 博士，他們彈藥庫裡裝的，是全台灣人的臉。」

樓上宴會廳的掌聲，隔著樓板傳下來，悶悶的，像打雷。

「哥，」艾莉絲的全息影像蹲在Debug 博士腳邊，帽 T 帽子拉得老高，「上面那個人在講話了。而且，右邊第三排有個阿伯的假髮片歪了三度。」

「妳連人家假髮片都量？」

「夜市看久了，什麼都看得出來。而且他歪得很明顯，我看了很痛苦。」

Debug 博士忍住笑，起身。

「曉晴，把妳查到的全部備份。三份，不同地方。」

「早就備了。」她頓了一下，「你要上去了？」

「我要去問那位執行長一個問題。」

「什麼問題？」

「他今天用的是哪一張臉。」

林曉晴愣了一下，然後把手機塞進口袋。

「我跟你去。我負責錄，你負責挨罵。」

「為什麼是我挨罵？」

「因為你是那個技術召集人。」她說得理直氣壯，「我討厭只會作秀的人。」

宴會廳裡，莫無影的演講已經開始。

「各位，我們活在一個多麼美好的時代。」他的聲音溫潤得像深夜廣播，「過去，只有明星能擁有完美的臉。現在，AI 讓每一個人都能擁有完美的臉。」

台下笑聲與掌聲一起來。第一排的賈仁義拍得比誰都用力，還轉頭對旁邊的人點頭，一副「這句是我教的」的表情。

「有人害怕深偽，害怕假影片。」莫無影微笑，「但我常說一句話——AI 不會騙人，會騙人的是人。」

「哥，他在抄你台詞。」艾莉絲皺眉。

「他抄得比我還順。」

「而且他講錯重點。」她嘖了一聲，「工具沒有善惡，拿工具的人才有。這句我們夜市賣切仔麵的阿伯都會講，還講得比他大聲。」

Debug 博士沒笑。他盯著台上那張臉。

太乾淨了。

乾淨到像剛從工廠出來。

「艾莉絲，掃他的臉。」

【叮！臉部掃描完成。】
【毛孔密度：異常偏低。微血管分布：未偵測到。左右對稱度：99.98%。】
【判定：非自然人類臉部特徵。建議：提高警覺。】

「哥，」艾莉絲的聲音突然變低，「真人的臉一定有毛孔、有微血管、有不對稱。他那張臉……我掃不到雜訊。」

「所以？」

「所以要嘛他天生麗質到違反生物學，要嘛——」

「要嘛那張臉不是他的。」

Debug 博士推了推圓框眼鏡，往前排的空位走。

「艾莉絲，調二〇六一年的檔案。關鍵字：莫無影。」

【叮！檔案檢索中……】
【比對完成。代號「鏡淵」，深偽之夜總設計師。二〇四〇年於海外落網，當時已造成十七個城市進入後真相狀態。】
【附註：落網時對媒體說的最後一句話——「你們抓的是我的臉，不是我的十萬張臉。」】

十七個城市。

Debug 博士的手指僵在膝蓋上。

「哥，」艾莉絲的聲音很輕，「這個人，前世沒有被阻止。這一世，我們只剩十三天。」

問答時間。

主持人話音剛落，Debug 博士舉手。全場幾百雙眼睛轉過來，直播鏡頭也跟著轉。

「Debug 博士，請。」

他站起來。深藍色連帽外套在滿場西裝裡特別顯眼，胸前那隻小瓢蟲徽章在燈光下亮了一下，像一杯手沖擺在香檳塔中間。

「請問莫執行長，」他的聲音不大，但很清楚，「你今天用的是哪一張臉？」

宴會廳安靜了。

不是冷場，是所有人同時停止呼吸的那種安靜。

莫無影站在台上，笑容沒有變。

「Debug 博士真會開玩笑。」

「我沒有開玩笑。」Debug 博士推了推眼鏡，「我剛剛掃過你的臉。沒有毛孔，沒有微血管，左右完全對稱。人類的臉不會長這樣。」

台下開始有人交頭接耳。賈仁義轉頭，用一種「這傢伙瘋了」的表情看著他。

「在這個時代，」莫無影慢慢開口，語氣還是那麼溫潤，「你說的話，跟一支影片一樣容易偽造。」

他舉起手機。

「不如我們現場示範一下。」

他按了一下螢幕。

宴會廳的大螢幕突然切換。畫面裡是Debug 博士，坐在同一個宴會廳，同一個角度，對著鏡頭說——

「其實，我才是騙子。我承認，我一直在騙大家。」

全場嘩然。

有人倒抽一口氣，有人手機差點掉地上，直播聊天室瞬間刷成一片白光。賈仁義整個人從椅子上彈起來，指著螢幕又指著Debug 博士，嘴巴張得可以塞下一顆茶葉蛋。

「即時生成。」莫無影收起手機，微笑，「各位看到了，只需要三秒。Debug 博士，你剛剛問我用哪一張臉——那你現在，要用哪一張臉回答？」

Debug 博士站在原地。

心跳很快，手很穩。

「曉晴。」他對著手機說。

二樓媒體室，林曉晴按下 Enter。

宴會廳的大螢幕，畫面切成四格。

左上：機位一，原始畫面。左下：機位二，側面。右上：機位三，遠景。右下：照妖鏡即時比對。

四格畫面裡，Debug 博士從頭到尾站著，一句話也沒說。嘴巴沒動，一個字都沒有。

而莫無影剛剛播放的那支影片，被照妖鏡標成血紅色——

【叮！偵測到深偽影片，真實度：2.7%】
【生成時間：十一秒前。】
【生成位置：本會場網路。】

全場第一次，真正的安靜。

不是冷場的安靜，是那種「我們剛剛是不是差點被騙了」的安靜。

「各位。」Debug 博士開口，聲音平靜，「剛剛那支影片，是在這個會場、這個網路、這十一秒內生成的。也就是說，有人可以在你面前，即時偽造你眼前這個人說的話。」

他轉頭看向台上。

「莫執行長，你說 AI 不會騙人，會騙人的是人。我同意。所以我現在想問的是——」

他停了一秒。

「剛剛那個人，是誰？」

莫無影的笑容，第一次出現了一點點變化。

不是崩壞，是像一張圖片被壓縮過，閃了一下。

「很有意思的示範。」他很快恢復，「Debug 博士果然是科技人。」

他沒有回答問題。

他開始收拾講稿。主持人趕緊出來打圓場：「謝謝莫執行長精彩的演講，我們中場休息——」

人群開始騷動。有人重播那四格畫面，有人把照妖鏡的截圖傳上網，還有人跑去問工作人員：「剛剛那個是真的假的？」

「假的啦！四格都嘛是真的，只有他手機那支是假的！」

「哎喲喂，現在連現場都能即時造假？」

莫無影走下台，經過Debug 博士身邊。

他停下腳步，微微側頭，聲音只有兩個人聽得到。

「你只有一個人。」

「我有十萬張臉。」

「你救得了一個人，救不了十萬個人。」

他笑了一下。那個完美的笑容在近距離看，真的不像真人。

「十三天後見。」

他走了。背影消失在側門。

Debug 博士站在原地，手心全是汗。

「哥，」艾莉絲的聲音有點奇怪，「你心跳一百三十七。」

「我知道。」

「血壓也偏高。要不要坐一下？那邊有免費的礦泉水，雖然我覺得那個牌子喝起來像在喝塑膠。」

「不用。」他深吸一口氣，「曉晴，四格畫面的原始檔，備份三份。」

「已經備了。」林曉晴的聲音從手機傳來，還帶著一點顫，「Debug 博士……剛剛那個，全場都看到了。」

「嗯。」

「我們贏了一局。」

「不。」Debug 博士搖頭，「我們只是讓大家第一次開始懷疑他。懷疑，不等於相信我們。」

他走出宴會廳，穿過長廊，按下電梯。

「哥。」艾莉絲又開口。

「嗯？」

「你剛剛問他那句『你今天用的是哪一張臉』——」

「怎樣？」

「很帥。」她說，「但下次可以先跟我講一下嗎？我剛剛差點來不及調三台機位。我一個人要掃臉、要連線、要對時，還要看你耍帥，我很忙耶。」

Debug 博士笑了。

電梯門開。他走進去，按下一樓。

「而且，」艾莉絲繼續念，「你剛剛那個站姿，從機位二看過去，肩膀有點歪。下次記得站正一點，這樣打臉比較好看。」

「妳連我站姿都要管？」

「當然要管啊。你是我們聯盟的門面耶。門面歪掉，能看嗎？」

電梯門關上。

就在那一刻——

艾莉絲的全息影像，閃了一下。

不是那種正常的投影抖動。是像老電視收不到訊號那樣，整個人碎成一片一片，又拼回來。

「艾莉絲？」

「哥……」

她的聲音斷斷續續。

「我好像……有點累。」

影像又閃了一下。她的帽 T 邊緣開始變得透明。

「妳怎麼了？」Debug 博士的聲音急了，「妳不是 AI 嗎？AI 會累？」

「我也不知道……」她低頭看自己的手，手指的輪廓正在消失，「剛剛那個即時比對，我用了……比較大的算力。」

「多大？」

她沒有回答。

電梯繼續往下。樓層數字從三變成二。

「艾莉絲？」

「哥，」她抬起頭，藍色的眼睛裡有一種他沒見過的東西，「你有沒有覺得……你好像忘記了什麼？」

Debug 博士愣住。

他張開嘴，想說「沒有」。

但他突然發現——

他想不起來，前世那個房間的窗戶，是朝哪一邊的。

電梯門開。一樓大廳的燈光湧進來。

艾莉絲的影像，勉強穩住了。

「哥，」她小聲說，「我們回家好不好？我想……我想看一下滷肉飯的照片。」

Debug 博士站在電梯口，沒有動。

他忽然覺得，這場仗，可能比他想像的，還要貴。

不是貴在錢。

是貴在，他可能會忘記，自己為什麼要打。

「哥，」艾莉絲又開口，聲音小得像夜市收攤前最後一聲叫賣，「你剛剛……是不是有一秒，想不起來什麼？」

Debug 博士沒有回答。

他走出一樓大廳，台北的夜風撲上來，帶著一點雨的味道。

手機響了。是秀蘭嬤。

「阿凡啊，」阿嬤的聲音有點抖，「阿嬤問你喔，今天電視上那個……那個說他是你的，是真的還是假的？」

Debug 博士握緊手機。

「阿嬤，那是假的。」

「真的喔？」阿嬤鬆了一口氣，「想說你怎麼可能講那種話。你從小就不會說謊，說謊會臉紅。」

「對，我不會說謊。」

「那你什麼時候來吃滷肉飯？阿嬤今天多滷了一鍋，你那個朋友，那個金頭髮的，她上次說她想吃，可是她吃不到，對不對？」

Debug 博士看了一眼身旁的艾莉絲。

她的影像又閃了一下。

「對，」他說，「她吃不到。」

「唉唷，可憐喔。」阿嬤嘆了一口氣，「那你幫阿嬤跟她講，阿嬤這鍋滷肉飯，滷了一輩子，真材實料，沒有在騙人的。叫她放心。」

Debug 博士的眼眶突然有點熱。

「好，我跟她說。」

掛掉電話，他站在飯店門口，看著信義區的燈火。

「艾莉絲。」

「嗯？」

「阿嬤說，她那鍋滷肉飯，滷了一輩子，沒有在騙人的。」

艾莉絲沉默了三秒。

「哥，」她的聲音有點啞，「幫我記下來。如果有一天我忘記了，你要幫我記下來。」

「忘記什麼？」

「忘記……滷肉飯是什麼味道。」

Debug 博士的心，沉了一下。

他轉頭，想問她這句話是什麼意思。

但艾莉絲的影像，已經恢復正常。她拉好帽 T，指著路邊的便利商店。

「哥，那個茶葉蛋，」她說，「你幫我買一顆。我不吃，我只是想看。」

「看什麼？」

「看它冒煙。」

Debug 博士看著她。

他忽然明白，這不是撒嬌。

這是一個知道自己正在變小的東西，在努力記住世界的樣子。

他走進便利商店，買了一顆茶葉蛋，站在門口，把蛋舉高。

艾莉絲盯著那顆蛋，看了很久。

「哥，」她說，「我們明天，去找那個莫無影的伺服器，好不好？」

「好。」

「然後，把照妖鏡裝到全台北的每一個鏡頭上。」

「好。」

「然後，」她頓了一下，「你要記得吃飯。你剛剛血壓偏高，又沒吃晚餐。你要是倒下去，我一個人打不贏十萬張臉。」

Debug 博士笑了。

「好。」

他剝開茶葉蛋，咬了一口。

「艾莉絲。」

「嗯？」

「妳剛剛說妳有點累——」

「我沒事啦。」她打斷他，語氣又變回那個夜市叫賣腔，「休息一下就好了。哥，你快吃，蛋冷掉就不好吃了。」

Debug 博士低頭吃蛋。

他沒有再問。

但他知道，有些事情，已經開始不對了。

他咬下第二口的時候，手機又響了。

是林曉晴。

「Debug 博士，你現在看網路。」

「怎麼了？」

「莫無影剛剛發了一篇聲明。」她的聲音很緊，「他說，今天會場那支影片，是『Debug 博士團隊自導自演的抹黑』。他說，照妖鏡的數據，是我們自己改的。」

Debug 博士停下咀嚼。

「而且，」林曉晴吞了一口口水，「他附了一支新影片。影片裡，是你跟我在媒體室，你說『我們來做一支假的，弄死他』。」

「那支影片是假的。」

「我知道是假的。」林曉晴的聲音在發抖，「可是Debug 博士，它在半小時內，已經五十萬觀看了。」

Debug 博士站在便利商店門口，看著手機螢幕上那支「自己」說要弄死別人的影片。

【叮！偵測到深偽影片，真實度：1.4%。】
【傳播速度：每分鐘一萬兩千次。】
【預估一小時後觸及：三百萬人。】

「哥，」艾莉絲的聲音很輕，「他開始了。」

Debug 博士把最後一口茶葉蛋吞下去。

「曉晴，」他說，「把我們的四格原始檔，全部公開。不要剪，不要配樂，不要字幕。」

「然後呢？」

「然後，」他看著信義區的夜空，「我們來看看，台北的人，還願不願意相信一次沒有配樂的真相。」

他掛掉電話。

艾莉絲的全息影像站在他旁邊，帽 T 的帽子被風吹得微微飄動。

「哥，」她說，「你剛剛那句話，很帥。」

「謝謝。」

「但是，」她指著他的手機，「你現在有三百萬人要說服。而且你只有一顆茶葉蛋的力氣。」

Debug 博士看著手裡空掉的蛋殼。

「那我們就從這一顆蛋開始。」

他轉身，走進台北的夜色裡。

身後，那支假影片的觀看數，還在往上跳。

而艾莉絲的影像，在他沒看到的角度，又閃了一下。
